Document¶

The document, its shortcuts and its export entry points.

class Document(width: float | Length | None = None, height: float | Length | None = None, *, size: str | PageSize | None = None, root: Svg | None = None, theme: Theme | str | None = None, **kwargs: Any)[source]¶

Bases: Building, Sizing, Theming, Typography, Output, Access, InkscapeData, ElementFactory

An SVG document under construction.

Shortcut methods (doc.circle(...), doc.linear_gradient(...)) build an element, add it and return it; definitions go into <defs>. Containers returned by shortcuts nest when used with with.

Parameters:

  • width (float or Length, optional) – Canvas size; a matching viewBox is added unless one is given. Defaults to None, which sizes the canvas from the content on output.

  • height (float or Length, optional) – Canvas size; a matching viewBox is added unless one is given. Defaults to None, which sizes the canvas from the content on output.

  • size (str or PageSize, optional) – A PageSize (svg.size.a4), or a named size instead of width and height: "a4", "letter", "slide-16:9", "instagram-post", … (see size), with -landscape or -portrait appended to turn it. Paper sizes are in millimetres or inches, so the viewBox counts in those units. Defaults to None.

  • root (Svg, optional) – Use an existing root instead of creating one. Defaults to None.

  • theme (Theme or str, optional) – Styles elements marked with as_role. Defaults to None, which keeps the theme that wrote the theme sheet of an existing root, else takes Theme.current() ("light" outside a with theme: block).

  • **kwargs – Forwarded to Svg.

Raises:

  • TypeError – If size is given together with width or height.

  • ValueError – If size is not a registered name.

See also

svgwriter.model.elements.Svg

The root element wrapped by a document.

svgwriter.library.preset.size

Add a named size.

Notes

doc += element (or a list) adds at the insertion point. Elements used as references (fill=gradient, clip_path=clip) go into <defs> automatically; doc.define(x) or doc.defs += x does it explicitly.

Examples

>>> from svgwriter import Rect
>>> doc = Document(100, 100)
>>> glow = doc.radial_gradient(cx=0.5, cy=0.5, r=0.5)
>>> with doc.group(fill="red") as g:
...     _ = doc.rect(10, 10, 20, 20)
...     _ = doc.circle(50, 50, 10, fill=glow)
>>> len(g)
2
>>> doc += Rect(0, 0, 5, 5)
>>> doc.root[-1].tag
'rect'
>>> page = Document(size="a4")
>>> page.root.get("width"), page.root.get("viewBox").width
(Length(value=210.0, unit=<Unit.MM: 'mm'>), 210.0)

classmethod from_string(text: str | bytes, format: str = 'svg', *, strictness: Strictness | None = None, **options: Any) → Document[source]¶

Parse text in any registered format into a document: SVG by default, or Mermaid, DOT, TikZ, …

Text formats that are usually files ("mermaid", "dot", "tikz", "markdown", "txt", "eps", …) are read from the string itself, with the same importer as open().

Parameters:

  • text (str or bytes) – The source; str is encoded as UTF-8 for formats read as bytes.

  • format (str, optional) – A format name or extension (see svg.formats.readers()). Defaults to "svg".

  • strictness (Strictness, optional) – How SVG treats unknown elements and unsupported attributes. Defaults to Strictness.LENIENT. SVG only.

  • **options (Any) – Options of the importer (for example theme= for Mermaid). SVG takes only theme=, the theme to restyle the document with (by default the one that wrote it is kept).

Returns:

Document – A document wrapping the parsed root.

Raises:

  • SVGParseError – If the text is malformed or, when strict, unsupported.

  • ValueError – If the root element is not <svg>, or format is not a registered importer.

  • TypeError – If strictness is given for a format other than SVG, or SVG is given an option other than theme.

See also

open

Read a file in any registered format.

Examples

>>> doc = Document.from_string('<svg xmlns="http://www.w3.org/2000/svg"><rect width="4" height="4"/></svg>')
>>> [element.tag for element in doc]
['rect']
>>> chart = Document.from_string("flowchart LR\n  A --> B", "mermaid")
>>> len(chart.root.children) > 0
True

Named sizes¶

Document(size="a4"), Scene.size and project files take a name or a PageSize from svg.size; svgwriter sizes lists the names. Paper and card sizes are in millimetres or inches, so the viewBox counts in those units; screen sizes are pixels. Append -landscape or -portrait to any name to turn it.

class PageSize(width: float, height: float, units: Unit = Unit.NONE)[source]¶

Bases: object

A canvas size: a width and a height counted in one unit.

Look the built-in ones up as attributes of svgwriter.size (svg.size.a4), add your own with svgwriter.library.preset.size, and pass either to Document(size=...), Scene.size or a project’s size.

Parameters:

  • width (float) – The two sides, in units.

  • height (float) – The two sides, in units.

  • units (Unit, optional) – The unit both sides are counted in. Defaults to Unit.NONE, user units (pixels).
