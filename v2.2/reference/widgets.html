Widgets¶

Controls for drawing functions, notebook panels and sweeps. svg.interact and svg.sweep are exported at the top level as well; the guide is Widgets.

svgwriter.widgets.interact(function, *[, ...])

Show function's drawing beside a panel of controls, redrawn as they change.

svgwriter.widgets.sweep(function, *[, dur, ...])

Step function's parameters over time and return the animation as a scene.

svgwriter.widgets.controls(**specs)

Declare the controls of a drawing function, by parameter name.

svgwriter.widgets.control(spec, *[, label])

The control a shorthand stands for.

svgwriter.widgets.controls_of(function, *[, ...])

The controls of function: those declared with controls(), then specs, labelled by name.

Live controls for drawing functions: notebook panels, preview forms and parameter sweeps.

A control is pure data (Slider, Segmented, ColorPicker, …), so one declaration drives a notebook panel (interact(), the widget extra), the form of svgwriter preview and an animation over time (sweep()). Shorthands stand in for controls: (0, 10) is a slider, ["a", "b"] a row of buttons, True a toggle and "#ff6347" a colour picker.

Example

>>> import svgwriter as svg
>>> @svg.widgets.controls(radius=(0, 30), color=["tomato", "gold", "teal"])
... def dot(radius=10, color="tomato"):
...     return svg.circle(30, 30, radius, fill=color)
>>> view = svg.interact(dot, backend=svg.widgets.Recorder())  # a panel in a notebook
>>> view.update(radius=25).code()
"dot(radius=25, color='tomato')"
>>> svg.sweep(dot, radius=(5, 30), dur=1).values_at(0.5)
{'color': 'tomato', 'radius': 18}

class Interactive(function: Callable[[...], Any], controls: Mapping[str, Control], backend: Backend, delay: float = 0.08)[source]¶

Bases: object

A drawing function with live controls; interact() makes one.

Parameters:

  • function (callable) – Returns a Document or an element for keyword arguments named like the controls.

  • controls (mapping of str to Control) – One control per parameter.

  • backend (Backend) – What shows the panel.

  • delay (float, optional) – Seconds to wait after the last change before redrawing. Defaults to 0.08; 0 redraws at once.

Variables:

  • controls (dict of str to Control) – The controls, by parameter name.

  • error (str or None) – The traceback of the last failed redraw, or None.

See also

interact

Build and show one in a notebook.

Examples

>>> import svgwriter as svg
>>> from svgwriter.widgets import Interactive, Slider
>>> class Quiet:
...     def panel(self, controls, values, changed): pass
...     def draw(self, svg): pass
...     def fail(self, message): pass
...     def show(self): pass
>>> dot = Interactive(lambda r: svg.circle(10, 10, r), {"r": Slider(1, 10)}, Quiet(), delay=0)
>>> dot.update(r=4).code()
'<lambda>(r=4.0)'

bake(fps: float | None = None, *, duration: float | None = None, tolerance: float = 0.01) → Document¶

A copy of the document whose SMIL plays what the behaviors and update() do.

The scene is sampled fps times a second. Each element’s changes become <animate>, <animateTransform> and <set> children with as few keyframes as keep every sample within tolerance: numbers and colours interpolate (a path’s d while its commands keep their shape), transforms split into translate, rotate, skew and scale, and other values switch with <set>. Changing text becomes one copy per text shown in turn, and elements added or removed are shown or hidden with visibility. The document’s own SMIL is kept and plays on top, as in the video. Anything SMIL cannot express is left out and listed in one warning.

Parameters:

  • fps (float, optional) – Samples per second. Defaults to the scene’s fps.

  • duration (float, optional) – Seconds to sample. Defaults to the scene’s duration, else the end of its SMIL.

  • tolerance (float, optional) – Largest difference allowed between the baked animation and a sample, in user units, degrees, scale factors or colour channels (0..1). Defaults to 0.01.

Returns:

Document – The baked copy; the scene’s own document keeps its Python state.

Raises:

ValueError – If no duration is set and the drawing has no SMIL animation.

See also

save

Uses this for .svg, .svgz, .html and .pptx.

Notes

Baking runs the behaviors and update() for every sample, so it leaves the scene at its last moment. What is not expressed: an element moved to another parent, changes of an id, CSS declarations that are not SVG properties, an attribute removed with no initial value to return to, and transforms squashed flat with a skew.

Examples

>>> import svgwriter as svg
>>> class Slide(svg.Scene):
...     width, height, fps, duration = 100, 20, 10, 1.0
...     def build(self, doc):
...         self.box = doc.rect(0, 5, 10, 10, fill="red")
...     def update(self, seconds):
...         self.box.x = 90 * seconds
>>> baked = Slide().bake()
>>> animation = baked[0].children[0]
>>> animation.tag, animation.get("values"), animation.get("keyTimes")
('animate', '0;90', '0;1')
>>> baked.at(0.5)[0].get("x")
'45'

sweep(function: Callable[[...], Any], *, dur: float = 2.0, fps: float | None = None, ease: Ease | str | tuple[float, float, float, float] | tuple[Any, ...] | Callable[[float], float] | None = None, name: str | None = None, **params: Any) → Sweep[source]¶

Step function’s parameters over time and return the animation as a scene.

Each keyword is a parameter: (start, end) of numbers, lengths or colours runs smoothly from one to the other (whole numbers when the parameter is declared with an IntSlider); a list steps through its items; a slider runs from its min to its max, options and toggles step through their values. Anything else is passed unchanged, and parameters with declared controls (controls()) that are not given keep their starting value.

Parameters:

  • dur (float, optional) – Seconds from start to end. Defaults to 2.

  • fps (float, optional) – Frames per second. Defaults to 30.

  • ease (str, tuple or callable, optional) – Timing curve ("ease-in-out", …). Defaults to None (linear).

  • name (str, optional) – Output name. Defaults to the function’s name.

  • **params (object) – Ranges, lists, controls and fixed values, by parameter name.

Returns:

Sweep – A scene: .save("x.svg") bakes SMIL; .gif, .mp4 and .pptx work as for any scene.

Raises:
