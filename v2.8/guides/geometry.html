Geometry and transforms¶

Local geometry, one transform¶

An element’s SVG coordinates (cx, x, width, d, points) are its local geometry and are written exactly as given. Everything that places the element afterwards edits its transform, t, an immutable affine Matrix.

import svgwriter as svg

c = svg.circle(50, 50, 10)
c.translate(20, 0).rotate(90)
print(c.cx)          # 50.0: the local geometry never changes
print(c.position)    # Point(x=70.0, y=50.0): where the anchor (centre) is now
print(c.matrix)           # the shortest equivalent transform text
print(c)             # <circle cx="50" cy="50" r="10" transform="..."/>

The anchor¶

Rotation, scaling, skewing and flipping pivot on the anchor, given in local coordinates. By default it is the centre of the element’s bounding box and follows geometry edits; set it to pin it.

r = svg.rect(0, 0, 40, 20)
print(r.anchor)              # Point(x=20.0, y=10.0)
r.anchor = (0, 0)            # pivot on the top-left corner from now on
r.rotate(30)
r.anchor = None              # back to the centre
r.rotate(-30, about=(100, 100))     # or pass a pivot for one call

Parent frame or local frame¶

Each method composes in the parent frame by default: translate(10, 0) moves ten units right on screen whatever the current rotation. local=True uses the element’s own (rotated, scaled) axes.

a = svg.rect(0, 0, 10, 10).rotate(90).translate(10, 0)                 # right on screen
b = svg.rect(0, 0, 10, 10).rotate(90).translate(10, 0, local=True)     # along its own x axis: down
print(a.position, b.position)

method

effect

translate(dx, dy)

move

rotate(degrees, about=None)

rotate, positive turns from +x towards +y

scale(sx, sy=None, about=None)

scale; negative factors mirror

skew(x_degrees, y_degrees)

shear

flip_x(), flip_y()

mirror about the anchor

apply(M)

compose any matrix

place(x, y) / position = (x, y)

move the anchor to a point

reset()

drop the transform

All return the element, so they chain. Gradients and patterns have the same methods; they edit gradientTransform and patternTransform.

Operators¶

Numbers and pairs transform a copy; element operands keep their structural meaning.

dot = svg.circle(0, 0, 5)
moved = dot + (10, 20)          # translated copy
bigger = dot * 2                # scaled copy about the anchor
turned = svg.rect(0, 0, 8, 2) @ 45      # rotated copy ("at 45 degrees")
shifted = svg.Matrix.translate(5, 0) @ dot      # matrix in the parent frame
group = dot + svg.circle(20, 0, 5)              # a <g> holding both
dot += (1, 1)                   # in place

* and @ never bake coordinates. To fold the transform into the geometry, convert: el.to_path() returns a <path> whose d already includes t.

Things to keep in mind:

  • A bare number broadcasts like numpy: el + 5 moves by (5, 5), while the method el.translate(5) follows SVG’s translate(5) and moves by (5, 0).

  • Operators never take elements out of a document: a + b copies operands that already have a parent. The in-place forms work in place: a -= b puts the resulting <path> where a was, keeping its id.

  • + groups and - cuts, so a + b - b is not a: the group is cut by b’s outline.

  • Images composite through their pixels: img.pixels | other.pixels (see Compositing images); on the element, numbers and offsets transform, so img * 2 scales.

Bounds¶

box = svg.rect(0, 0, 10, 10).rotate(45)
print(box.local_bbox())     # before the transform
print(box.bounds())         # after it, in parent coordinates
print(box.exact_bbox())     # tight box of the transformed outline

Placing and aligning¶

Boxes have edges (left, right, top, bottom) and named points (center, top_left, top_center, bottom_right, …; box.point("top") is the middle of the top edge). Elements use the same names to move by their bounds:

title = svg.rect(0, 0, 80, 20)
badge = svg.circle(0, 0, 6).align(title, "center_left", to="center_right", offset=(4, 0))
note = svg.rect(0, 0, 30, 8).align(title, "top_left", to="bottom_left", offset=(0, 2))
logo = svg.Polygon.regular(0, 0, 10, 5).place(100, 100, at="bottom_right")
print(note.bounds().top, badge.bounds().left)

place(x, y, at=...) moves a named point onto a coordinate; align(target, at, to=...) moves it onto a point of another element, box or (x, y), so a.align(b, "top", to="bottom") stacks a under b.

Elements also have the box’s edges and points as attributes. Reading one gives the edge (a number) or point of the element’s bounds; assigning one moves the element so that edge or point lands there:

card = svg.rect(20, 20, 100, 50)
heading = svg.rect(0, 0, 40, 8)
heading.center = card.center              # centred on the card
heading.top = card.top + 4                # then 4 units below the card's top edge
pin = svg.circle(0, 0, 3)
pin.center = card.bottom_right            # on the card's corner
print(heading.top_left, pin.center)

Units and angles¶

Plain numbers are user units (CSS pixels, 96 per inch). Lengths carry units and combine across them; the result keeps the left side’s unit:

width = 5 * svg.inch - 7 * svg.mm            # 4.7244in
print(width.to("mm"), svg.inch(1) / svg.mm(25.4))
page = svg.Document(210 * svg.mm, 297 * svg.mm)   # A4; coordinates inside are millimetres
# page.save("print.png", dpi=300)
spin = svg.rect(0, 0, 4, 2) @ svg.turn(0.25)  # angles: deg, rad, grad, turn

A document sized in a physical unit with a matching viewBox, such as svg.Document(size="a4") or the page above, counts its user units in that unit. Lengths you give there mean the same thing everywhere: rect(width=svg.mm(20)), stroke_width=svg.pt(1), layout gaps and path tools such as round_corners(svg.mm(3)) all resolve against the page, so the rectangle is written as width="20" and prints 20 mm wide in browsers and in every export (writing 20mm there would make browsers scale the millimetres a second time). Lengths set on an element before it joins the page convert when it is added; attribute text read from an SVG file keeps its SVG meaning. Lengths compare by physical size, and a user-unit length equals the plain number: svg.Length(5) == 5 and svg.inch(1) == svg.mm(25.4).

The units are px, pt, pc, mm, q (quarter millimetres, written Q), cm, inch, em, ex and percent. Units SVG has no suffix for are written in the nearest SVG unit: m, km, um (micrometres) and nmi (nautical miles) as millimetres; ft, yd, mi, furlong and mil (thousandths of an inch) as inches. A unit on its own is one of itself, so height=svg.inch is one inch and svg.turn is a full turn. svg.length(value, unit) and svg.angle(value, unit) take the unit as text, spelled short or in full ("mm", "millimetres", "inches", "degrees", "gon", "turns", …); output always uses the short suffix.

print(svg.length(1.2, "metres"), svg.length(2, "ft"), svg.Length.parse("3 inches"))
print(svg.angle(0.25, "turns"), svg.angle(100, "gon").to("deg"))

em, ex and % only combine with themselves, because converting them needs a font size or a reference length. dpi= on raster exports sets pixels per inch (96 is scale=1).

Calculating with units¶

Multiplying and dividing lengths and angles works like a maths problem: the dimensions travel with the numbers as powers of length and angle. A length times a length is an area (a Quantity), dividing it by a length gives a length again, and a length over a length is a plain number. An attribute only accepts the dimension it needs, so mistakes surface where the value is used:

area = svg.mm(30) * svg.mm(20)               # 600mm², dimension length²
side = area / svg.mm(40)                     # 15mm, a Length again
ratio = svg.inch(1) / svg.mm(25.4)           # 1.0
spin = svg.deg(90) / svg.mm(10)              # length⁻¹·angle: turn per millimetre
print(area, side, ratio, spin * svg.mm(5))   # ... 45deg
box = svg.rect(0, 0, side, side)
try:
    box.width = area
except TypeError as error:
    print(error)                             # width needs a length, got length²
tip = svg.mm(10) @ svg.deg(30)               # a Point: 10mm at 30 degrees from +x

Angles have helpers for direction work. Positive angles turn from +x towards +y, clockwise on screen; ccw=True asks for the counter-clockwise way round:

heading = svg.deg(350)
print(heading.diff(10), heading.diff(10, ccw=True))   # 20deg, -340deg (shortest arc, then forced)
print(heading.lerp(10, 0.5).wrap(), svg.deg(-90).wrap())   # 0deg, 270deg
print(svg.deg(30).sin(), svg.deg(100).clamp(0, 90), svg.deg(100).clamp(350, 20, circular=True))
print(svg.turn(0.25).arclength(svg.mm(20)))            # 31.4159mm

Many elements from arrays¶

Class.many(**columns) builds many elements in one call; scalars apply to all and arrays give one value each, like numpy broadcasting. Colors can be names, one color, or an (n, 3|4) array:

import numpy as np

xs = np.linspace(0, 100, 50)
dots = svg.Circle.many(cx=xs, cy=50 + 20 * np.sin(xs / 10), r=2, fill=np.random.rand(50, 3))
cloud = svg.group(*dots)

Matrices and numpy¶

import numpy as np

m = svg.Matrix.rotate(90) @ svg.Matrix.scale(2)
points = np.array([[1.0, 0.0], [0.0, 1.0]])
print(m @ points)                    # maps (..., 2) arrays in one step
print(np.asarray(m).shape)           # (3, 3) homogeneous matrix
