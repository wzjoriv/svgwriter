# svgwriter examples

A numbered learning path: each example is a short step-by-step script that builds on the ones before it. Run one with `python examples/<name>.py`, or open the notebook beside it to see every step as a picture. Saved files are written to the folder you run the example from.

| # | Example | Notebook | What it shows | Key APIs |
|--:|---|---|---|---|
| 01 | [01_basic_shapes.py](01_basic_shapes.py) | [ipynb](01_basic_shapes.ipynb) | Shapes, gradients, text and nested groups through document shortcuts. | `svg.Document`, `svg.LinearGradient`, `doc.group`, `svg.ellipse` |
| 02 | [02_transforms_and_layout.py](02_transforms_and_layout.py) | [ipynb](02_transforms_and_layout.ipynb) | Rotate, flip, clip and place shapes, then lay them out by the named points of their bounds. | `rotate`, `flip_x`, `place`, `align`, `bounds`, `BBox.point` |
| 03 | [03_paths_and_geometry.py](03_paths_and_geometry.py) | [ipynb](03_paths_and_geometry.ipynb) | Path data, arcs and markers; boolean operations; length, tight bounds, points along an outline and hit tests. | `svg.PathBuilder`, `svg.markers`, `union`, `stroked`, `total_length`, `point_at_length`, `contains_point` |
| 04 | [04_typography.py](04_typography.py) | [ipynb](04_typography.ipynb) | Live text: styled ranges, per-character moves, outlines, cut-outs, Hindi, Bengali, Urdu, Japanese and Chinese lines, and typeface weights and metrics. | `svg.text`, `text[a:b].wrap`, `glyphs`, `direction`, `svg.Typeface` |
| 05 | [05_paint_and_filters.py](05_paint_and_filters.py) | [ipynb](05_paint_and_filters.ipynb) | Gradients, patterns, clip paths and masks, then filter primitives for shadows, noise, lighting, displacement, images and color. | `svg.Pattern`, `svg.ClipPath`, `svg.Mask`, `svg.Filter`, `svg.filters.drop_shadow` |
| 06 | [06_pixels_and_compositing.py](06_pixels_and_compositing.py) | [ipynb](06_pixels_and_compositing.ipynb) | numpy pixels beside vectors, and Porter-Duff operators between pixels, shapes and text. | `svg.Image`, `to_image`, `Pixels.composite`, `Pixels.on_grid` |
| 07 | [07_formats.py](07_formats.py) | [ipynb](07_formats.ipynb) | One drawing exported to SVG, PNG, PDF, EPS, TikZ, PowerPoint and DXF, then read back; a postcard sized in millimetres with lengths in inches and points and angles in degrees and turns. | `doc.save`, `svg.Document.open`, `Document(size=)`, `svg.mm`, `svg.pt`, `svg.deg`, `svg.turn` |
| 08 | [08_math_and_diagrams.py](08_math_and_diagrams.py) | [ipynb](08_math_and_diagrams.ipynb) | LaTeX formulas as outlines and a Mermaid flowchart imported as native elements. | `svg.latex`, `svg.Document.open` |
| 09 | [09_animation.py](09_animation.py) | [ipynb](09_animation.ipynb) | Animation presets, the animation elements beneath them, stills, a GIF and async writing. | `element.animate`, `doc.at`, `svg.AnimateTransform`, `write_many_async` |
| 10 | [10_procedural_animation.py](10_procedural_animation.py) | [ipynb](10_procedural_animation.ipynb) | A scene class moved by `update(seconds)` and rendered with `python -m svgwriter animate`. | `svg.Scene`, `build`, `update`, `fps`, `duration` |
| 11 | [11_interop.py](11_interop.py) | [ipynb](11_interop.ipynb) | Adding matplotlib figures, networkx graphs and objects with `__svgwriter__`, `_repr_svg_` or `_repr_png_`. | `doc.add`, `__svgwriter__`, `_repr_svg_`, `_repr_png_` |
| 12 | [12_logo.py](12_logo.py) | [ipynb](12_logo.ipynb) | An app logo with light, dark and mono variants, and the SVG, PNG, ICO and ICNS assets made from it. | `svg.Theme`, `svg.rect`, `stroked`, `doc.save(pixels=, sizes=)` |
| 13 | [13_scenes.py](13_scenes.py) | [ipynb](13_scenes.ipynb) | Several scenes in one file, one SMIL-driven and one moved from Python, rendered by name. | `svg.Scene`, `render`, `save`, `svgwriter animate --list` |
| 14 | [14_themes.py](14_themes.py) | [ipynb](14_themes.ipynb) | One drawing in every built-in theme and all of them side by side, a variant computed with `=` expressions, a TOML theme saved back with its comments and a default set with `with`. | `svg.Theme`, `as_role`, `theme.replace`, `Theme.from_toml`, `to_toml`, `Document(theme=)` |
| 15 | [15_powerpoint.py](15_powerpoint.py) | [ipynb](15_powerpoint.ipynb) | Slides as documents saved to one `.pptx` with native shapes, text and an editable equation, then read back. | `svg.export.save`, `svg.latex`, `Document.open_all`, `Document(theme=)` |
| 16 | [16_behaviors.py](16_behaviors.py) | [ipynb](16_behaviors.ipynb) | Reusable Python motion attached to elements, and the scene baked into SMIL so the SVG plays like the video. | `@svg.preset.behavior`, `Scene.attach`, `element.home`, `Scene.bake` |
| 17 | [17_layout.py](17_layout.py) | [ipynb](17_layout.ipynb) | A calculator card from stacks and a grid that re-lays itself out when the gap, padding or a label changes. | `svg.VStack`, `svg.HStack`, `svg.Grid`, `svg.Spacer`, `grid.span` |
| 18 | [18_widgets.py](18_widgets.py) | [ipynb](18_widgets.ipynb) | An adjustable playing card: rank and suit on button rows, hue and corner radius on sliders, a glow toggle; a still per suit and a sweep saved as animated SVG and GIF. | `@svg.widgets.controls`, `svg.interact`, `svg.sweep`, `Segmented`, `Slider`, `Toggle` |
| 19 | [19_presets.py](19_presets.py) | [ipynb](19_presets.ipynb) | Pattern, gradient, filter and marker catalogues; a sentence whose words smoke, shine, blow, burn and snow while staying text, saved as SVG and GIF; gooey blobs; a text effect of your own. | `svg.patterns`, `svg.gradients`, `svg.filters`, `svg.markers`, `text[a:b].effect`, `@svg.preset.text_effect` |
| 20 | [20_fonts.py](20_fonts.py) | [ipynb](20_fonts.ipynb) | A handwritten-style alphabet drawn with strokes, saved as OTF and TTF and used for text at once; an icon font of four icons with its stylesheet and cheatsheet. | `svg.FontBuilder`, `glyph`, `icon`, `kern`, `save_css`, `cheatsheet`, `typeface` |
