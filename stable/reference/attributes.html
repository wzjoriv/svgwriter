resolve_styles(root: Element) → None[source]¶

Rewrite a tree so CSS and inline styles become presentation attributes.

The tree is modified in place: matching rule declarations and inline style values are written as attributes and the style attribute is removed; <style> sheets, now folded in, are removed too, so later lookups do not apply their rules a second time over inline values. Renderers that ignore CSS then see the same result. The CSS-only marker shorthand becomes marker-start, marker-mid and marker-end, and CSS units, which are case-insensitive (20PX), are written in the lower case attributes require.

Parameters:

root (Element) – The root of the tree to rewrite.

Examples

>>> import svgwriter as svg
>>> from svgwriter.attributes.cascade import resolve_styles
>>> doc = svg.parse('<svg xmlns="http://www.w3.org/2000/svg"><rect style="fill:red"/></svg>')
>>> resolve_styles(doc)

rules_of(root: Element) → list[Rule][source]¶

Collect the rules of every <style> element under an element.

Parameters:

root (Element) – The element to search, including itself.

Returns:

list of Rule – The rules in document order, numbered consecutively.

See also

parse_css

Parse a single sheet.

Examples

>>> import svgwriter as svg
>>> from svgwriter.attributes.cascade import rules_of
>>> doc = svg.parse('<svg xmlns="http://www.w3.org/2000/svg"><style>.a{fill:red}</style></svg>')
>>> [rule.selector for rule in rules_of(doc)]
['.a']
