Geometry operations and rendering¶

Boolean operations, measurement, text outlines and rendering, backed by skia.

Geometry backed by skia: boolean operations, measurement, text outlines.

The same features are reachable from elements: a | b, a & b, a - b, a ^ b, shape.total_length(), shape.contains_point(x, y) and so on.

Example

>>> import svgwriter as svg
>>> from svgwriter import ops
>>> ring = svg.Circle(50, 50, 40) - svg.Circle(50, 50, 20)
>>> ops.contains(ring, 50, 50)
False

composite_rgba(source: ndarray, backdrop: ndarray, operator: CompositeOperator | BlendMode | str = CompositeOperator.OVER, *, k: Sequence[float] = ()) → ndarray[source]¶

Composite source onto backdrop.

Both are straight (unpremultiplied) RGBA in 0..1 and broadcast against each other, so a (1, 1, 4) color composites onto a whole image.

Parameters:

  • source (numpy.ndarray) – (..., 4) RGBA drawn on top (A in Porter-Duff terms).

  • backdrop (numpy.ndarray) – (..., 4) RGBA underneath (B).

  • operator (CompositeOperator, BlendMode or str, optional) – How to combine them, as in feComposite and feBlend. Defaults to "over".

  • k (sequence of float, optional) – (k1, k2, k3, k4) for "arithmetic": k1*A*B + k2*A + k3*B + k4 on premultiplied values. Defaults to ().

Returns:

numpy.ndarray – float32 straight RGBA with the broadcast shape.

Raises:

ValueError – If the operator is unknown, the shapes do not broadcast, or arithmetic lacks four k terms.

See also

svgwriter.elements.structure.Pixels.composite

Composite the pixels of images.

Notes

The math follows the SVG 1.1 feComposite and feBlend definitions on premultiplied color.

Examples

>>> import numpy as np
>>> from svgwriter.ops import composite_rgba
>>> red = np.array([[[1, 0, 0, 0.5]]])
>>> composite_rgba(red, np.array([[[0, 0, 1, 1]]])).round(2).tolist()
[[[0.5, 0.0, 0.5, 1.0]]]
>>> composite_rgba(red, np.zeros((2, 2, 4)), "in").shape
(2, 2, 4)

interpolate(a: T, b: T, t: float) → T[source]¶

The value a fraction t of the way from a to b (t=0 gives a, t=1 gives b).

Works on numbers, (x, y) points and numeric sequences, colors (in RGBA), Matrix (translation, rotation, skew and scale separately, so turns stay turns), PathData and elements. Two elements of the same kind and shape interpolate their attributes; anything else is morphed as outlines: outlines pair with outlines and holes with holes (a contour without a partner grows from or shrinks to its centre), each pair is resampled to one point count and started where the points move least, so in-between shapes do not twist. Inside elements, attribute values that cannot be blended (keywords, different strings, lists of different lengths) switch at t = 0.5, as SMIL’s discrete mode does. Other types are added with register_interpolator().

Parameters:

  • a (object) – Start and end values of the same kind.

  • b (object) – Start and end values of the same kind.

  • t (float) – Fraction of the way; values outside 0..1 extrapolate numbers.

Returns:

object – A new value; neither input is changed.

Raises:

TypeError – If no rule blends a with b (for example a number and a color).

See also

svgwriter.Color.mix

Color blending on its own.

register_interpolator

Teach interpolate a new type.

Examples

rasterize_many(documents: Iterable[Document], *, processes: int | None = None, dtype: Any = <class 'numpy.float32'>, **options: Any) → list[np.ndarray][source]¶

Rasterize several documents in parallel worker processes.

Each document travels to a worker as SVG text, so anything the SVG keeps renders the same as document.rasterize(**options); linked files are resolved against each document’s source path.

Parameters:

  • documents (iterable of Document) – The drawings (frames of an animation, a batch of icons, …).

  • processes (int, optional) – Worker count. Defaults to None (one per CPU); 1 renders in this process.

  • dtype (numpy dtype, optional) – numpy.float32 (0..1, like rasterize) or numpy.uint8 (0..255, four times less data to move between processes). Defaults to float32.

  • **options – scale, size, padding, background as for Document.rasterize().

Returns:

list of numpy.ndarray – float32 RGBA arrays in the order of documents.

Notes

Start-up costs a fraction of a second, so pools pay off from a few dozen non-trivial documents; small batches run in this process. Scripts that use this on Windows or macOS need the usual if __name__ == "__main__": guard.

Examples

>>> import svgwriter as svg
>>> from svgwriter.ops import rasterize_many
>>> frames = [svg.Document(4, 4) for _ in range(2)]
>>> [a.shape for a in rasterize_many(frames, processes=1)]
[(4, 4, 4), (4, 4, 4)]

Teach interpolate() to blend values of a new kind.
