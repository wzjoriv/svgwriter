Geometry operations and rendering¶

Boolean operations, measurement, text outlines and rendering, backed by skia.

Font families live here too: Typeface (also svg.Typeface), its Face objects with FaceMetrics, and the low-level register_font; see Typography. Document.embed_fonts writes the faces a document uses as @font-face rules.

Geometry backed by skia: boolean operations, measurement, text outlines.

The same features are reachable from elements: a | b, a & b, a - b, a ^ b, shape.total_length(), shape.contains_point(x, y) and so on.

Example

>>> import svgwriter as svg
>>> from svgwriter import ops
>>> ring = svg.Circle(50, 50, 40) - svg.Circle(50, 50, 20)
>>> ops.contains(ring, 50, 50)
False

class Face(family: str, weight: tuple[float, float], style: ~typing.Literal['normal', 'italic', 'oblique'], stretch: tuple[float, float], axes: dict[str, tuple[float, float, float]] = <factory>, source: ~pathlib.Path | None = None, subfamily: str = 'Regular', typeface: ~typing.Any = None, blob: bytes | None = None)[source]¶

Bases: object

One face of a Typeface: a font file and the styles it covers.

Faces are made by Typeface; read them from Typeface.faces or pick one with Typeface.face(). A variable face covers a weight (and stretch) range; Typeface.face() returns it pinned to the requested weight.

Variables:

  • family (str) – The family name text uses to reach this face.

  • weight ((float, float)) – The weights covered; equal ends for a static face.

  • style ({"normal", "italic", "oblique"}) – The style.

  • stretch ((float, float)) – The widths covered, in percent of normal.

  • axes (dict of str to (float, float, float)) – Variation axes by tag ("wght", "wdth", "slnt", …) as (minimum, default, maximum); empty for a static face.

  • source (pathlib.Path or None) – The file the face came from; None for installed or in-memory fonts.

  • subfamily (str) – The style name inside the font (typographic name first), such as "SemiBold Italic".

Examples

>>> import svgwriter as svg
>>> face = svg.Typeface("sans-serif").face(weight=700)
>>> face.measure("Hi", 20) > 0
True

class Typeface(name: str, faces: Iterable[str | PathLike[str] | bytes | BinaryIO] | Mapping[tuple[float, str], str | PathLike[str] | bytes | BinaryIO] | None = None)[source]¶

Bases: object

A font family: the faces (weights, styles, widths) that share one name.

Use it wherever a family name goes (font_family=, font=, theme fonts); text then gets the face that CSS font matching picks for its font-weight and font-style. Faces loaded from files are registered for rendering at once, so nothing needs installing. css() and Document.embed_fonts write @font-face rules so saved SVG files carry the fonts.

This is not Font, the SVG 1.1 <font> element that defines glyphs inside a document.

Parameters:

  • name (str) – The family name. Alone, it loads the installed family (generic names such as "serif" pick the first installed candidate).

  • faces (iterable of path or bytes, or mapping of (weight, style) to path or bytes, optional) – Font files instead of installed fonts. A mapping states each file’s weight and style itself, overriding what the file says. Defaults to None.

Raises:

  • LookupError – If faces is None and no such family is installed.

  • ValueError – If a file is not a font.

See also

register_font

Register one file (what this does for each face).

Examples

>>> import svgwriter as svg
>>> sans = svg.Typeface("sans-serif")
>>> bold = sans.face(weight=700)
>>> bold.metrics.units_per_em > 0
True
>>> label = svg.text("Total", x=0, y=20, font_family=sans, font_weight="bold")
>>> str(label.computed("font_family")) == str(sans)
True

combine(first: Geometry, second: Geometry, op: BooleanOp) → PathData[source]¶

Combine two outlines with a boolean operation.

The result has no self-intersections; the named helpers union(), intersection(), difference() and xor() call this. Boolean operations work on filled areas: an open path counts as closed by a straight line, so a lone line or polyline with no area adds nothing. When that leaves the result empty a warning says so.

draw_graph(graph: Any, *, layout: Layout = 'spring', size: float = 400.0, labels: bool = True, edge_labels: bool = False, node_radius: float = 12.0, node_fill: Any = '#4c9be8', edge_stroke: Any = '#555555', edge_width: float = 1.5, seed: int = 0) → Group[source]¶

Draw a networkx, igraph or rustworkx graph as SVG elements you can restyle afterwards.

Nodes become <circle> elements (id node-<name>), edges <line> elements, or arcs when an edge runs both ways in a directed graph, with arrowheads for directed graphs, and labels <text>. Per-node and per-edge attributes override the defaults: fill, radius, label, stroke, width; an edge’s label (or else its weight) is written at its middle when edge_labels.

Each library’s own attributes are read: networkx node and edge data, igraph vertex and edge attributes (vertices keyed by name when set, else by index), and rustworkx payloads (a dict holds attributes; any other node payload is its label, any other edge payload its weight).

Parameters:

  • graph (networkx.Graph, igraph.Graph, rustworkx.PyGraph or rustworkx.PyDiGraph) – Directed or not; multigraphs are drawn as simple edges.

  • layout (str, mapping, sequence or callable, optional) – A layout of the graph’s own library: "spring", "circular", "kamada_kawai" and "random" work for all three, plus that library’s others (networkx "spectral", igraph "sugiyama", rustworkx "spiral", …). Or ready positions: {node: (x, y)}, a library’s own result (an igraph Layout, a rustworkx Pos2DMapping) or points in node order; or a function f(graph) returning any of these. Defaults to “spring”.

  • size (float, optional) – Side of the square the layout is fitted into. Defaults to 400.

  • labels (bool, optional) – Write node names (or their label attribute). Defaults to True.

  • edge_labels (bool, optional) – Write each edge’s label or weight attribute at its middle. Defaults to False.

  • node_radius (optional) – Default node and edge style.

  • node_fill (optional) – Default node and edge style.

  • edge_stroke (optional) – Default node and edge style.

  • edge_width (optional) – Default node and edge style.

  • seed (int, optional) – Seed for random layouts, so drawings are reproducible. Defaults to 0.

Returns:

Group – <g> with an edges group and a nodes group.

Raises:

  • TypeError – If graph is not a graph of a supported library.

  • ValueError – If the layout name is unknown to the graph’s library, or positions are missing for some nodes.

See also

Takes graphs directly, drawn with the defaults.

Notes

Examples

interpolate(a: T, b: T, t: float) → T[source]¶

The value a fraction t of the way from a to b (t=0 gives a, t=1 gives b).

Works on numbers, (x, y) points and numeric sequences, colors (in RGBA), Matrix (translation, rotation, skew and scale separately, so turns stay turns), PathData and elements. Two elements of the same kind and shape interpolate their attributes; anything else is morphed as outlines: outlines pair with outlines and holes with holes (a contour without a partner grows from or shrinks to its centre), each pair is resampled to one point count and started where the points move least, so in-between shapes do not twist. Two batches (svgwriter.batch) of the same size blend every item at once. Inside elements, attribute values that cannot be blended (keywords, different strings, lists of different lengths) switch at t = 0.5, as SMIL’s discrete mode does. Other types are added with register_interpolator().

Parameters:

  • a (object) – Start and end values of the same kind.

  • b (object) – Start and end values of the same kind.

  • t (float) – Fraction of the way; values outside 0..1 extrapolate numbers.

Returns:

object – A new value; neither input is changed.

Raises:

TypeError – If no rule blends a with b (for example a number and a color).

See also

rasterize_many(documents: Iterable[Document], *, processes: int | None = None, dtype: Any = <class 'numpy.float32'>, **options: Any) → list[np.ndarray][source]¶

Rasterize several documents in parallel worker processes.

Each document travels to a worker as SVG text, so anything the SVG keeps renders the same as document.rasterize(**options); linked files are resolved against each document’s source path.

  • documents (iterable of Document) – The drawings (frames of an animation, a batch of icons, …).

round_corners(item: Geometry, radius: float, where: CornerFilter = None, *, fillet: Fillet = 'arc') → PathData[source]¶

Replace sharp corners with fillets of radius.

A fillet shrinks when its neighbours are too short for the radius (sharing a side with another fillet leaves each half of it), so the outline never overlaps itself. Fillets between straight sides are exact circular arcs; next to curves they are cubic curves that leave and join the curves smoothly, a fillet’s reach from the vertex.
