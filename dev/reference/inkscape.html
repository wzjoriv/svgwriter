Inkscape¶

Layers, labels, editable stars and arcs, connectors, guides and export hints; see the Inkscape guide. Document.layer, Document.layers, Document.guides, Document.guide and Document.export_hints are documented with Document.

Inkscape documents: layers, labels, editable stars and arcs, connectors, guides and export hints.

Files saved by Inkscape read and write back with their inkscape: and sodipodi: data intact; this package gives that data a Python interface. Document exposes the common parts directly (doc.layer, doc.layers, doc.guides, doc.export_hints).

class Guide(x: float, y: float, angle: float = 0.0, label: str | None = None, color: str | None = None, locked: bool = False)[source]¶

Bases: object

A guide line, in the document’s user units with y pointing down.

Parameters:

  • x (float) – A point the line passes through.

  • y (float) – A point the line passes through.

  • angle (float, optional) – Direction of the line in degrees, clockwise from the x axis: 0 is horizontal, 90 vertical. Defaults to 0.

  • label (str, optional) – The name shown next to the guide. Defaults to None.

  • color (str, optional) – Guide colour, as Inkscape writes it ("#0000ff"). Defaults to None.

  • locked (bool, optional) – Whether the guide can be dragged. Defaults to False.

See also

svgwriter.Document.guides

Read or replace a document’s guides.

Notes

Inkscape stores guide positions from the bottom-left of the viewBox with y pointing up, and the orientation as the line’s normal; reading and writing convert both, so guides line up with the drawing’s own coordinates.

Examples

>>> from svgwriter.formats.inkscape import Guide
>>> Guide.vertical(10).angle, Guide.horizontal(5, label="base").y
(90.0, 5)

class Star(path: Element)[source]¶

Bases: _Shape

The editable parameters of an Inkscape star or polygon.

A live view on a <path sodipodi:type="star">: reading a property reads the sodipodi: attribute, and assigning one writes it and redraws d the way Inkscape does, so the file stays an editable star in Inkscape.

Parameters:

path (Path) – A path carrying sodipodi:type="star".

Raises:

ValueError – If path is not an Inkscape star.

See also

Arc

The same for ellipses and arcs.

svgwriter.library.paths.star

inkscape=True builds one.

Notes

Angles are in degrees, clockwise from the x axis (Inkscape stores radians). inkscape:randomized is kept but not applied to the redrawn outline; Inkscape applies it again when it opens the file.

Examples

>>> import svgwriter as svg
>>> star = svg.inkscape.Star.create(50, 50, 40, 20, 5)
>>> view = svg.inkscape.Star(star)
>>> view.sides = 6
>>> star.get("sodipodi:sides"), len(star.d)
(6, 13)

connect(path: Element, start: Element | None, end: Element | None, *, kind: str = 'polyline') → None[source]¶

Make path an Inkscape connector from start to end.

Both ends receive an id if they have none. When both ends have known bounds, the path is redrawn as a straight line between their centres; Inkscape reroutes it around obstacles when the file is edited there.

Parameters:

  • path (Element) – A <path>.

  • start (Element or None) – The objects to join; None leaves that end loose, and None for both turns the path back into a plain path.

  • end (Element or None) – The objects to join; None leaves that end loose, and None for both turns the path back into a plain path.

  • kind ({"polyline", "orthogonal"}, optional) – Inkscape’s routing style. Defaults to "polyline".

Raises:

ValueError – If kind is unknown.

Examples

>>> import svgwriter as svg
>>> a, b = svg.circle(0, 0, 5, id="a"), svg.circle(40, 0, 5, id="b")
>>> line = svg.Path(stroke="black")
>>> root = svg.svg(a, b, line)
>>> svg.inkscape.connect(line, a, b)
>>> str(line.d), line.attributes["inkscape:connection-end"]
('M0 0 L40 0', '#b')
