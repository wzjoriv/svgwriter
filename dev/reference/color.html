Color parsing and the <paint> type.

as_color(value: Color | str | Sequence[float]) → Color[source]¶

Coerce a ColorLike into a Color.

Parameters:

value (Color or str or sequence of float) – A color, color text, or a 3- or 4-sequence of floats in 0..1.

Returns:

Color – value itself if it is already a Color.

Raises:

  • ValueError – For unknown names or channels outside 0..1.

  • TypeError – For anything that is not a color.

See also

Parse text only.

Examples

>>> from svgwriter.color import as_color
>>> as_color("blue").hex
'#0000ff'
>>> as_color((1, 0, 0)).hex

class Color(r: float, g: float, b: float, a: float = 1.0, icc: str | None = None, name: str | None = None)[source]¶

Bases: ColorChannels, ColorBlending, Drawable

An sRGB color with straight alpha; every channel is a float in 0..1.

Colors are immutable, support + (even mix), * and / (scaling), and iterate as r, g, b, a.

Parameters:

  • r (float) – Red, green and blue in 0..1.

  • g (float) – Red, green and blue in 0..1.

  • b (float) – Red, green and blue in 0..1.

  • a (float, optional) – Alpha (opacity) in 0..1; 1 is opaque. Defaults to 1.0.

  • icc (str, optional) – An icc-color(...) specification kept alongside the sRGB value. Defaults to None.

  • name (str, optional) – Keyword written instead of hex (set when parsed from a name); ignored when comparing. Defaults to None.

Raises:

ValueError – If any channel is outside 0..1.

See also

as_color

Coerce names, tuples and colors into a Color.

parse_color

Parse CSS color text.

Notes

Everything that takes a color also takes a ColorLike: a name or CSS string, a Color, or a 3/4-tuple of floats in 0..1 (as in matplotlib). Use from_uint8() for 0..255 values. SVG 1.1 has no alpha in colors, so a translucent fill/stroke/stop-color/ flood-color also writes the matching *-opacity attribute.

Examples

>>> from svgwriter.color import Color
>>> Color(1, 0.5, 0).hex
'#ff8000'
>>> Color.parse("#f80").uint8
(255, 136, 0, 255)
>>> Color.from_uint8(255, 0, 0, 128).a
0.5019607843137255
>>> str(Color.parse("red") + "blue")
'#800080'
>>> Color.parse("rgba(0, 0, 255, 0.25)").a
0.25
