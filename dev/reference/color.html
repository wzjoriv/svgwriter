parse_color(text: str) → Color[source]¶

Parse a color keyword, hex or CSS Color 4 function into sRGB.

Functions: rgb()/rgba() (numbers are 0..255, percentages 0..100%), hsl()/hsla(), hwb(), hsv()/hsva(), lab(), lch(), oklab(), oklch(), color(<space> r g b) with srgb, srgb-linear, display-p3, a98-rgb, rec2020, xyz/xyz-d65 or xyz-d50, and device-cmyk(). Both the comma syntax and the modern space-separated syntax with / alpha work; none stands for a zero channel; hues take deg, rad, grad or turn. Colors outside the sRGB gamut are clipped to it. device-cmyk() is the naive formula with no profile; real CMYK goes through a trailing icc-color(...), which is preserved. Results are cached.

Parameters:

text (str) – Color text such as "tomato", "#f80", "rgb(255 0 0 / 50%)" or "oklch(62.8% 0.2577 29.23)".

Returns:

Color – The parsed color.

Raises:

ValueError – If the text is not a recognized color.

See also

as_color

Also accepts colors and channel sequences.

Examples

>>> from svgwriter.model.color import parse_color
>>> parse_color("tomato").uint8
(255, 99, 71, 255)
>>> parse_color("hsl(120, 100%, 50%)").hex
'#00ff00'

class Color(r: float, g: float, b: float, a: float = 1.0, icc: str | None = None, name: str | None = None, *, source: tuple[str, tuple[float, float, float]] | None = None)[source]¶

Bases: ColorText, ColorBlending, ColorAdjustments, ColorTones, ColorDifference, Drawable

An sRGB color with straight alpha; every channel is a float in 0..1.

Colors are immutable, support + (even mix), * and / (scaling), and iterate as r, g, b, a.

Parameters:

  • r (float) – Red, green and blue in 0..1.

  • g (float) – Red, green and blue in 0..1.

  • b (float) – Red, green and blue in 0..1.

  • a (float, optional) – Alpha (opacity) in 0..1; 1 is opaque. Defaults to 1.0.

  • icc (str, optional) – An icc-color(...) specification kept alongside the sRGB value. Defaults to None.

  • name (str, optional) – Keyword written instead of hex (set when parsed from a name); ignored when comparing. Defaults to None.

  • source (tuple of (str, tuple of float), optional) – The colour space and unclipped channels the color was given in, as set by from_space(), CSS Color 4 text and mixing; None for plain sRGB. Defaults to None.

Raises:

ValueError – If any channel is outside 0..1.

See also

as_color

Coerce names, tuples and colors into a Color.

parse_color

Parse CSS color text.

Notes

Everything that takes a color also takes a ColorLike: a name or CSS string, a Color, or a 3/4-tuple of floats in 0..1 (as in matplotlib). Use from_uint8() for 0..255 values.

r, g and b are always sRGB, clipped to its gamut, and drive hex, rgba and SVG output. A color given in another space (oklch(...), color(display-p3 ...)) also keeps that space and its exact values in source: coords(), mix(), tint(), delta() and to_css() work from them, so wide-gamut colors are not clipped before they are mixed. SVG 1.1 has no alpha in colors, so a translucent fill/stroke/stop-color/ flood-color also writes the matching *-opacity attribute.

Examples

>>> from svgwriter.model.color import Color
>>> Color(1, 0.5, 0).hex
'#ff8000'
>>> Color.parse("#f80").uint8
(255, 136, 0, 255)
>>> Color.from_uint8(255, 0, 0, 128).a
0.5019607843137255
>>> str(Color.parse("red") + "blue")
'#800080'
>>> Color.parse("rgba(0, 0, 255, 0.25)").a
0.25

mix(other: ColorLike, weight: Opacity = 0.5, space: MixSpace = 'srgb') → Color¶

Blend with another color in a chosen space.

Parameters:

  • other (Color or str or sequence of float) – The color to mix in.

  • weight (float, optional) – Share of other in the result, from 0 to 1. Defaults to 0.5.

  • space ({"srgb", "linear", "display-p3", "lab", "lch", "oklab", "oklch", "xyz"}, optional) – Where to interpolate: sRGB channels, linear-light sRGB (physically even blending of light), Display P3, CIE Lab or LCH, OKLab (perceptually even steps), OKLCH (OKLab with hue taken the shorter way round, so saturated colors stay saturated) or CIE XYZ (D65). Defaults to "srgb".

Returns:

Color – The blended color; alpha is blended linearly. When either color carries a source (a wide-gamut or non-sRGB color), both are mixed from their exact values and the result keeps the mixed values in space, so nothing is clipped until output.

Raises:

ValueError – If other is not a valid color or space is unknown.

Examples

>>> from svgwriter.model.color import Color
>>> Color.parse("red").mix("blue", 0.25).hex
'#bf0040'
>>> Color.parse("red").mix("blue", 0.5, space="oklch").hex
'#ba00c2'
>>> p3 = Color.parse("color(display-p3 0 1 0)").mix("white", 0.5, space="display-p3")
>>> p3.to_css("display-p3")
'color(display-p3 0.5 1 0.5)'
