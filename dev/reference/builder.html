Composite shapes and effects¶

Presets that build a ready-to-draw element from a few numbers: shapes and lines. Shadows, glows and markers are in the preset libraries. Every preset forwards keyword arguments to the element it builds, so fill=, stroke= and id= work as they do on the plain classes, and the result takes transforms, place(...) and boolean operations like any other element.

import svgwriter as svg
from svgwriter import builder

doc = svg.Document(240, 120)
doc += builder.callout(10, 10, 120, 50, tail=(40, 100), fill="white", stroke="black")
doc += builder.heart(180, 40, 50, fill="crimson")
doc += builder.wave(10, 100, 220, amplitude=6, wavelength=40, stroke="steelblue")

cutout = badge - builder.cross(180, 85, 14)

Presets carry a theme role, so they follow the document theme: registered shapes are shape (filled with the palette’s primary color), callout is box, arrow is arrow.line, grid is grid, spiral and wave are line; outline, dashed_line and dot are outline, line and dot. Presentation keywords you pass go into the inline style, so they win over the role. grid, spiral and wave return open paths with fill="none". wave takes kind="sine" (smooth cubic segments), "square", "triangle" or "sawtooth".

Your own presets¶

A shape preset is a function that returns an element. Decorating it with @svg.preset.shape registers it under the function’s name (or name=) beside the built-in shapes (the list behind svgwriter shapes), and checks at call time that it really returns an element. A taken name raises ValueError naming the function that owns it, built-in shapes included; replace=True replaces one on purpose. svg.preset.shape(role="shape") gives the built elements a theme role; role=None leaves them unthemed.

import svgwriter as svg


@svg.preset.shape
def badge(cx: float, cy: float, r: float, **kwargs: object) -> svg.Group:
    ring = svg.Circle(cx, cy, r, fill="none", stroke="black")
    dot = svg.Circle(cx, cy, r / 3, **kwargs)
    return svg.Group(ring, dot)


print("badge" in svg.preset.list("shape"), badge(10, 10, 6, fill="gold").tag)
make = svg.preset.get("shape", "badge")
svg.preset.unregister("shape", "badge")

Follow the conventions of the built-in presets so yours feel the same: position and size as positional arguments, options as keyword-only arguments, and style attributes passed through **kwargs to the element. A package can publish presets by defining them with svg.preset.shape in a module; importing that module registers them. svg.preset.get("shape", name) then looks a preset up by name, and svg.preset.list("shape") lists everything available. Animation presets work the same way (see the animation guide), and so do patterns, filters, gradients, markers and text effects (see the Presets guide).

Preset functions¶

Presets of your own, by kind, each found by name.

Animations, behaviors, shapes, patterns, filters, gradients, markers and text effects register by decorator (name=, replace=) and sizes by a call (svg.preset.size(name, width, height)); every kind has list(kind), get(kind, name) and unregister(kind, name). A taken name raises an error naming its owner, built-in presets included; replace=True replaces one on purpose. Registered patterns, filters, gradients, markers and text effects join their catalogues (svg.patterns, svg.filters, svg.gradients, svg.markers, svg.text_effects) beside the built-in ones.

Example

>>> import svgwriter as svg
>>> @svg.preset.animation
... def lift(motion: svg.Motion, *, height: float = 8) -> svg.Motion:
...     return motion.move_by(0, -height)
>>> _ = svg.rect(0, 0, 4, 4).animate.lift(height=2)
>>> "lift" in svg.preset.list("animation")
True
>>> svg.preset.unregister("animation", "lift")
animation(function: F, /) → F[source]¶
animation(*, name: str | None = None, replace: bool = False) → Callable[[F], F]

Register a function as an animation preset, so element.animate.<name>(...) calls it.

The function stays an ordinary typed function: Motion.apply calls it with full completion and type checking, and the name works wherever presets are looked up by name (element.animate.bob(...), Motion.stagger).

Parameters:

  • function (callable, optional) – function(motion, *, option=default, ...) -> Motion: the first positional parameter is the element’s Motion, every option is keyword-only with a default, and it returns the motion for chaining (returning None is accepted). Given when used as a bare decorator.

  • name (str, optional) – The preset name. Defaults to None, which takes the function’s name.

  • replace (bool, optional) – Replace a preset already registered under the name, a built-in one included. Defaults to False.

Returns:

callable – The function unchanged, or a decorator that registers and returns it.

Raises:

  • TypeError – If the function’s parameters do not have that shape.

  • ValueError – If the name is not an identifier, or is taken and replace is False; the message names the owner.

See also

svgwriter.preset.unregister

Remove it again (unregister("animation", name)).

svgwriter.preset.list

Every animation preset (list("animation")).

Notes

A replaced built-in stays reachable as a class attribute, so a replacement can wrap it: svg.Motion.spin(motion, ...).

Examples

>>> @svg.preset.animation
... def bob(motion: svg.Motion, *, height: float = 8, dur: float = 1, begin: float = 0) -> svg.Motion:

>>> dot = svg.circle(10, 10, 4)

behavior(function: F, /) → F[source]¶
behavior(*, name: str | None = None, replace: bool = False) → Callable[[F], F]

Register a function as a behavior: Python motion that a Scene runs before every frame.

A behavior sets the element’s state at an absolute time, so frames can be drawn in any order. Attach it with Scene.attach (typed with the function’s own options) or by name, element.animate.<name>(...), once the element is in a scene’s document. Saving the scene as SVG or PowerPoint bakes it into SMIL (Scene.bake).

Parameters:

  • function (callable, optional) – function(element, seconds, *, option=default, ...) -> None: the element and the time in seconds come first, and every option is keyword-only with a default. Given when used as a bare decorator.

  • name (str, optional) – The behavior name. Defaults to None, which takes the function’s name.

  • replace (bool, optional) – Replace a behavior already registered under the name, a built-in one included. Defaults to False.

Returns:

callable – The function unchanged, or a decorator that registers and returns it.

Raises:

  • TypeError – If the function’s parameters do not have that shape.

  • ValueError – If the name is not an identifier, is an animation preset’s, or is taken and replace is False; the message names the owner.

See also

svgwriter.preset.animation

SMIL presets, the other half of element.animate.

svgwriter.Element.home

The element as it was when its first behavior was attached.

Notes

Start from element.home rather than the current state, so each frame is computed afresh instead of adding to the last one: element.t = element.home.t and then a relative move.

Build a periodic line along a horizontal axis.

The sine wave is made of cubic segments, one per half wavelength; the other kinds are polylines. The wave is cut at width, so it need not hold a whole number of wavelengths.

  • width (float) – Length of the wave along the axis.

  • wavelength (float) – Length of one full cycle.

  • kind ({"sine", "square", "triangle", "sawtooth"}, optional) – Shape of the wave. Sine and triangle start on the centerline and rise first; square starts at the crest; sawtooth starts at the trough and ramps up. Defaults to "sine".

  • **kwargs – Presentation attributes forwarded to Path; fill defaults to "none".

Path – The open wave.

Raises:
