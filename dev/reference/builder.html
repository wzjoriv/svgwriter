Composite shapes and effects¶

Presets that build a ready-to-draw element from a few numbers: shapes, lines, shadows, glows and markers. Every preset forwards keyword arguments to the element it builds, so fill=, stroke= and id= work as they do on the plain classes, and the result takes transforms, place(...) and boolean operations like any other element.

import svgwriter as svg
from svgwriter import builder

doc = svg.Document(240, 120)
doc += builder.callout(10, 10, 120, 50, tail=(40, 100), fill="white", stroke="black")
doc += builder.heart(180, 40, 50, fill="crimson")
doc += builder.wave(10, 100, 220, amplitude=6, wavelength=40, stroke="steelblue")
badge = builder.regular_polygon(180, 85, 14, 6, corner_radius=3, fill="gold")
cutout = badge - builder.cross(180, 85, 14)

grid, spiral and wave return open paths with fill="none", so give them a stroke. wave takes kind="sine" (smooth cubic segments), "square", "triangle" or "sawtooth".

Your own presets¶

A preset is a function that returns an element. Decorating it with shape_factory(name) registers it in SHAPES, the registry behind python -m svgwriter shapes, and checks at call time that it really returns an element. The name must be unique; registering it twice raises ValueError.

import svgwriter as svg
from svgwriter.builder import SHAPES, shape_factory


@shape_factory("badge")
def badge(cx: float, cy: float, r: float, **kwargs: object) -> svg.Group:
    ring = svg.Circle(cx, cy, r, fill="none", stroke="black")
    dot = svg.Circle(cx, cy, r / 3, **kwargs)
    return svg.Group(ring, dot)


print("badge" in SHAPES, badge(10, 10, 6, fill="gold").tag)
make = SHAPES.get("badge")
SHAPES.remove("badge")

Follow the conventions of the built-in presets so yours feel the same: position and size as positional arguments, options as keyword-only arguments, and style attributes passed through **kwargs to the element. A package can publish presets by defining them with shape_factory in a module; importing that module registers them. SHAPES.get(name) then looks a preset up by name, and SHAPES.names() lists everything available.

Composite shapes (star, gear, heart, callout, wave, …), effects (shadows, glows, markers) and presets.

Plain elements are built with the classes or their lowercase aliases (svg.circle); this module adds what the element classes do not provide.

drop_shadow(dx: float = 2.0, dy: float = 2.0, blur: float = 2.0, color: Color | str = 'black', opacity: Annotated[float, ValueRange(low=0.0, high=1.0)] = 0.5, **kwargs: Any) → Filter[source]¶

Build a drop-shadow filter.

The filter makes a blurred, offset, tinted copy of the source alpha and merges it under the source graphic. The filter region is enlarged so the shadow is not clipped.

Parameters:

  • dx (float, optional) – Shadow offset. Defaults to 2.0.

  • dy (float, optional) – Shadow offset. Defaults to 2.0.

  • blur (float, optional) – Gaussian standard deviation. Defaults to 2.0.

  • color (Color or str, optional) – Shadow color. Defaults to "black".

  • opacity (float, optional) – Shadow opacity. Defaults to 0.5.

  • **kwargs – Forwarded to Filter.

Returns:

Filter – A filter to add to <defs> and reference with filter="url(#id)".

See also

glow

A soft halo instead of an offset shadow.

Examples

>>> import svgwriter as svg
>>> from svgwriter.builder import drop_shadow
>>> shadow = drop_shadow(dx=3, dy=3, blur=1)
>>> type(shadow).__name__, len(shadow.children)
('Filter', 5)

Build graph paper: horizontal and vertical lines over a rectangle.

Give either rows and cols, which split the rectangle into that many cells, or spacing.

Parameters:

  • y (float) – Top-left corner.

  • width (float) – Size of the grid.

  • cols (int, optional) – Number of cell rows and columns; the grid has one more line of each, border included.

  • spacing (float or (float, float), optional) – Distance between lines, or (horizontal, vertical) distances. Lines start at the top-left corner and stop at the last one that fits.

  • **kwargs – Presentation attributes forwarded to Path; fill defaults to "none".

Returns:

Path – All lines as one path.

Raises:

ValueError – If neither or both of the cell counts and spacing are given, or a count or spacing is not positive.

shape_factory(name: str) → Callable[[Callable[[P], E]], Callable[[P], E]][source]¶

Register a function returning an element under name.

The wrapper checks the return type, so plugins fail loudly. Registered shapes are listed by python -m svgwriter shapes and drawn by python -m svgwriter draw.

Parameters:

name (str) – The name to register the shape under.

Returns:

callable – A decorator that registers the function and returns the checking wrapper.

Raises:

  • ValueError – If name is already registered.

  • TypeError – When the decorated function is called and does not return an element.

See also

SHAPES

The registry of shapes.

Examples

>>> from svgwriter import Circle
>>> from svgwriter.builder import shape_factory
>>> from svgwriter.builder import SHAPES
>>> @shape_factory("disc")
... def disc(cx, cy, r, **kwargs):
...     return Circle(cx, cy, r, **kwargs)
>>> disc(0, 0, 2).tag
'circle'
>>> _ = SHAPES.remove("disc")

wave(x: float, y: float, width: float, *, amplitude: float, wavelength: float, kind: str = 'sine', **kwargs: Any) → Path[source]¶

Build a periodic line along a horizontal axis.

The sine wave is made of cubic segments, one per half wavelength; the other kinds are polylines. The wave is cut at width, so it need not hold a whole number of wavelengths.

Parameters:

  • x (float) – Start of the axis; y is the centerline.

  • y (float) – Start of the axis; y is the centerline.

  • width (float) – Length of the wave along the axis.

  • amplitude (float) – Distance from the centerline to the crests.

  • wavelength (float) – Length of one full cycle.

  • kind ({"sine", "square", "triangle", "sawtooth"}, optional) – Shape of the wave. Sine and triangle start on the centerline and rise first; square starts at the crest; sawtooth starts at the trough and ramps up. Defaults to "sine".

  • **kwargs – Presentation attributes forwarded to Path; fill defaults to "none".

Returns:

Path – The open wave.

Raises:

ValueError – If kind is unknown or width or wavelength is not positive.

See also

spiral

A smooth curve around a center.

Examples

>>> from svgwriter.builder import wave
>>> box = wave(0, 20, 100, amplitude=10, wavelength=50).bbox
>>> round(box.height, 1)
20.0
>>> len(wave(0, 0, 40, amplitude=5, wavelength=20, kind="square").d)
8
