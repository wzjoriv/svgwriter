class Angle(value: float, unit: str = 'deg')[source]¶

Bases: object

An angle with a unit; float(angle) is degrees, as every svgwriter rotation expects.

Any two angles add, subtract and compare whatever their units; plain numbers count as degrees, as in SVG. Positive angles turn from +x towards +y, which is clockwise on screen. Multiplying or dividing by lengths and angles gives a ~svgwriter.model.attributes.quantity.Quantity.

Parameters:

  • value (float) – The magnitude.

  • unit (str, optional) – "deg", "rad", "grad" or "turn", or a spelled-out name ("degrees", "radians", "gon", "turns", …). Defaults to “deg”.

Examples

>>> import svgwriter as svg
>>> float(svg.turn(0.25)), str(svg.rad(1) + 30)
(90.0, '1.5236rad')
>>> svg.rect(0, 0, 4, 2).rotate(svg.rad(math.pi / 2)).matrix.decompose()[2]
90.0
>>> str(Angle(2, "radians"))
'2rad'

Parameters:

class Length(value: float, unit: Unit = Unit.NONE)[source]¶

Bases: object

A number with an optional unit.

The unit may be spelled out ("millimetres", "inches"); metres and feet are accepted too and stored as millimetres and inches, since SVG has no such units. Multiplying or dividing by other lengths and angles gives a ~svgwriter.model.attributes.quantity.Quantity (an area, for instance) that turns back into a length when the dimensions cancel.

Parameters:

  • value (float) – The magnitude.

  • unit (Unit or str, optional) – The unit; Unit.NONE means user units. Defaults to Unit.NONE.

See also

Unit

The available units.

Examples

>>> from svgwriter.model.attributes import Length, Unit
>>> str(Length(2.5, Unit.MM))
'2.5mm'
>>> Length.parse("1in").to_user_units()
96.0
>>> str(Length(1.5, "metres")), str(Length(2, "ft"))
('1500mm', '24in')
>>> Length(96) == 96, Length(1, "in") == 96, Length(1, "em") == 16
(True, True, False)

Bases: Length

class Quantity(value: float, length: int = 0, angle: int = 0, length_unit: Unit | None = None, angle_unit: str = 'rad')[source]¶

Bases: object

A value of dimension length^n · angle^m, the result of multiplying or dividing lengths and angles.

Arithmetic works like a maths problem: products add exponents, quotients subtract them, and sums need equal dimensions. Results that are plain lengths, angles or numbers come back as Length, Angle or float, in the unit of the first length or angle involved.

Parameters:

  • value (float) – Magnitude in user units^length · radians^angle.

  • length (int, optional) – Exponents of length and angle. Default to 0.

  • angle (int, optional) – Exponents of length and angle. Default to 0.

  • length_unit (Unit, optional) – Unit used to show lengths and to give back a Length. Defaults to user units.

  • angle_unit (str, optional) – Unit used to show angles and to give back an Angle. Defaults to “rad”.

See also

dimension_name

How a dimension reads.

Examples

>>> import svgwriter as svg
>>> area = svg.mm(3) * svg.mm(2)
>>> str(area), area.dimension
('6mm²', 'length²')
>>> area / svg.mm(4)
Length(value=1.5, unit=<Unit.MM: 'mm'>)
>>> svg.mm(6) / svg.mm(3)
2.0

Products and quotients of lengths and angles: values carrying dimension exponents.

mm(3) * mm(2) is an area, deg(90) / mm(5) an angle per length. Each Quantity stores its magnitude in base units (user units for length, radians for angle) with the exponents of both; once a calculation comes back to a plain length, angle or number it is a Length, an Angle or a float again.

class Quantity(value: float, length: int = 0, angle: int = 0, length_unit: Unit | None = None, angle_unit: str = 'rad')[source]¶

Bases: object

A value of dimension length^n · angle^m, the result of multiplying or dividing lengths and angles.

Arithmetic works like a maths problem: products add exponents, quotients subtract them, and sums need equal dimensions. Results that are plain lengths, angles or numbers come back as Length, Angle or float, in the unit of the first length or angle involved.

Parameters:

  • value (float) – Magnitude in user units^length · radians^angle.

  • length (int, optional) – Exponents of length and angle. Default to 0.

  • angle (int, optional) – Exponents of length and angle. Default to 0.

  • length_unit (Unit, optional) – Unit used to show lengths and to give back a Length. Defaults to user units.

  • angle_unit (str, optional) – Unit used to show angles and to give back an Angle. Defaults to “rad”.

resolve_styles(root: Element) → None[source]¶

Rewrite a tree so CSS and inline styles become presentation attributes.

The tree is modified in place: matching rule declarations and inline style values are written as attributes and the style attribute is removed; <style> sheets, now folded in, are removed too, so later lookups do not apply their rules a second time over inline values. Renderers that ignore CSS then see the same result. The CSS-only marker shorthand becomes marker-start, marker-mid and marker-end, and CSS units, which are case-insensitive (20PX), are written in the lower case attributes require.
