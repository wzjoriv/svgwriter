svg_value(precision: int = 4, *, pivot: tuple[float, float] | None = None, box: Any = None) → str¶

The shortest transform text for this matrix.

Rigid motions become rotate(a cx cy); otherwise the parts of translate rotate skewX scale that are not identity, falling back to matrix(...) when that is shorter.

Parameters:

  • precision (int, optional) – Maximum number of decimal places. Defaults to the library default precision.

  • pivot ((float, float), optional) – The element’s own pivot (its anchor). When a pure rotation’s centre would fall outside box, the text becomes translate(dx dy) rotate(a px py) about this point instead, which is what a person would write. Defaults to None.

  • box (BBox, optional) – The element’s local bounding box, used with pivot. Defaults to None.

Returns:

str – Text suitable for a transform attribute; empty for the identity.

Examples

>>> from svgwriter.transform import Matrix
>>> Matrix.rotate(90, 5, 5).svg_value()
'rotate(90 5 5)'
>>> (Matrix.translate(10, 5) @ Matrix.scale(2, 3)).svg_value()
'matrix(2 0 0 3 10 5)'
>>> Matrix.skew_x(30).svg_value()
'skewX(30)'
