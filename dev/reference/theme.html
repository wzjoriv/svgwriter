Themes¶

Palettes, fonts and role styles; see the Themes guide. svg.Theme and svg.themes are also available at the top level; every registry works like svg.Registry.

Themes: palettes, fonts and role styles that documents apply as CSS classes.

A Theme is immutable. Elements opt in with element.as_role("box"); a document writes one <style> rule per role it uses, so the SVG stays portable and can be restyled by swapping the sheet. Built-in themes are light (the default), dark, paper, print, mono, noir, brutalist, dracula, alucard, one-dark and one-light.

class Fonts(family: Family = 'Helvetica, Arial, sans-serif', monospace: Family = 'Consolas, Menlo, monospace', sizes: Mapping[str, float]=<factory>, weights: Mapping[str, int]=<factory>)[source]¶

Bases: object

Font families, named sizes (user units) and named weights.

Parameters:

  • family (str or Typeface, optional) – CSS font-family of ordinary text, or a Typeface (registered for rendering, embeddable with Document.embed_fonts). Defaults to a sans-serif stack.

  • monospace (str or Typeface, optional) – CSS font-family of code, or a typeface. Defaults to a monospace stack.

  • sizes (mapping of str to float, optional) – Named font sizes such as "text" and "title". Defaults to text 14, title 24, subtitle 18 and caption 11.

  • weights (mapping of str to int, optional) – Named weights such as "regular" and "bold". Defaults to 400 and 700.

See also

Theme

Uses these values in its text roles.

Examples

>>> from svgwriter.model.theme import Fonts
>>> fonts = Fonts().replace(sizes={"title": 30})
>>> fonts.sizes["title"], fonts.sizes["text"]
(30, 14.0)
>>> fonts.lookup("weights.bold")
700

class Palette(sources: Mapping[str, Color | str | Sequence[float] | Callable[[Palette], Color | str | Sequence[float]]])[source]¶

Bases: Mapping[str, Color]

Immutable color roles, resolved once from literals, references, expressions and functions.

Parameters:

sources (mapping of str to color or str or callable) – Each role’s source: a color ("#0f766e", "navy", a Color), a reference to another role written "{palette.name}", an expression marked with a leading = such as "=lighten({palette.primary}, 0.2)" (see the Themes guide), or a function that receives this palette and returns a color (lambda p: p.foreground.mix(p.background, 0.3)).

Raises:

ThemeError – If a reference names a missing role, references form a cycle or nest too deeply, an expression is malformed, or a value is not a color.

See also

Theme

Combines a palette with fonts and role styles.

Notes

Sources are kept, so replace() derives again: replacing foreground also changes every role computed from it. Roles read as attributes (palette.primary) or keys.

Examples

>>> from svgwriter.model.theme import Palette
>>> p = Palette({"ink": "#000000", "paper": "white", "line": lambda p: p.ink.mix(p.paper, 0.5)})
>>> p.line.hex
'#808080'
>>> p.replace(ink="#ff0000").line.hex
'#ff8080'
>>> Palette({"ink": "navy", "label": "=readable({palette.ink})"}).label.hex
'#ffffff'

class Theme(name: str, palette: Palette | Mapping[str, PaletteSource], fonts: Fonts | None = None, roles: Mapping[str, RoleSource] | None = None)[source]¶

Bases: ThemeFiles

Colors, fonts and the styles of named roles, applied to documents as CSS classes.

Parameters:

  • name (str) – A short name, used by get() once registered and written to theme files.

  • palette (Palette or mapping) – Color roles (see Palette). border, muted and shadow are derived from foreground and background, and on_primary from primary, unless given.

  • fonts (Fonts, optional) – Families, sizes and weights. Defaults to Fonts().

  • roles (mapping of str to style or callable, optional) – Extra or replaced role styles, merged over the standard roles. Each is a mapping of CSS properties (values may be literals, "{palette.name}"/"{fonts.sizes.name}" references, expressions such as "={fonts.sizes.text} * 1.5" or functions of the theme) or a function of the theme returning one. Defaults to None.

Raises:

ThemeError – If a role name is invalid or anything cannot be resolved.

See also

svgwriter.Document

Takes theme=; elements opt in with as_role.

Notes

A theme never changes. replace() builds variants, and with theme: makes it the default for documents created in the block (a context variable, so threads and tasks stay separate). Outside any block the default is the registered "light" theme.

Examples

>>> import svgwriter as svg
>>> dark = svg.themes.get("dark")
>>> dark.style("box")["fill"].hex
'#1f2937'
>>> brand = dark.replace(name="brand", palette={"primary": "#ff6600"})
>>> brand.style("shape")["fill"].hex
'#ff6600'
>>> with brand:
...     svg.Document(10, 10).theme.name
'brand'

replace(*, name: str | None = None, palette: Mapping[str, PaletteSource] | None = None, fonts: Fonts | Mapping[str, Any] | None = None, roles: Mapping[str, RoleSource] | None = None) → Theme[source]¶

A variant: palette entries, font values and role properties merge into this theme’s.

A variant of a registered theme extends it; a variant of anything else keeps what that theme extends and the file it was read from, so save() writes only what changed.

Parameters:

  • name (str, optional) – The variant’s name. Defaults to None, which keeps this name.

  • palette (mapping, optional) – Palette sources to replace or add; derived roles follow. Defaults to None.

  • fonts (Fonts or mapping, optional) – A whole Fonts, or keywords of Fonts.replace(). Defaults to None.

  • roles (mapping, optional) – Role sources; a mapping merges property by property into the existing role, a function replaces it. Defaults to None.

Returns:

Theme – The new theme.

Examples

>>> import svgwriter as svg
>>> light = svg.themes.get("light")
>>> bold = light.replace(roles={"line": {"stroke-width": 4}}, fonts={"sizes": {"text": 16}})
>>> str(bold.style("line")), bold.fonts.sizes["text"]
('fill:none;stroke:#0f766e;stroke-width:4px', 16)

The theme <style> sheet of a tree: the roles it uses and the sheet written while it is output.

applied(theme: Theme, root: Element) → Generator[None, None, None][source]¶

Hold the theme sheet in root for the duration of the block.

The sheet is a <style id="svgwriter-theme"> with rules for the roles in use. An existing one (from a parsed file) has its text replaced; otherwise one is inserted at the top. The tree is restored on exit. Nothing is written when no role is used and no sheet exists.

Parameters:

  • theme (Theme) – The theme to apply.

  • root (Element) – The root <svg>.

Yields:

None

Examples

>>> import svgwriter as svg
>>> from svgwriter.model.theme.sheet import applied
>>> root = svg.Svg(svg.circle(0, 0, 1).as_role("dot"))
>>> with applied(svg.themes.get("mono"), root):
...     root[0].css
'.role-dot { fill:#000000;stroke:#000000;stroke-width:1px }'
>>> len(root)
1

sheet_theme(root: Element) → Theme | None[source]¶

The theme that wrote the theme sheet of a parsed tree, so reopening a file keeps its look.

A registered theme that writes exactly that sheet is returned; otherwise the current theme with the sheet’s role styles, named "document".

Parameters:

root (Element) – The root <svg>.

Returns:

Theme or None – The theme, or None when the tree has no theme sheet.

Examples

>>> import svgwriter as svg
>>> from svgwriter.model.theme.sheet import sheet_theme
>>> doc = svg.Document(10, 10, theme="dark")
>>> _ = doc.circle(5, 5, 2).as_role("dot")
