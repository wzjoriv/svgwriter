Animation export¶

Frame rendering and ffmpeg encoding.

Turning documents into video and GIF files through ffmpeg.

svgwriter does not rasterize by itself. A renderer is any callable renderer(document, seconds) returning PNG bytes or an (height, width, 4) uint8 RGBA array; frames are piped to ffmpeg. The "skia" renderer is built in.

Example

>>> import svgwriter as svg
>>> doc = svg.Document(64, 64)
>>> dot = doc.circle(32, 32, 4, fill="tomato")
>>> def grow(document, t):
...     dot.r = 4 + 20 * t
>>> doc.render_animation("grow.gif", fps=12, duration=1, renderer="skia", update=grow)
class Video(path: AnyPath, *, ffmpeg: str | None = None)[source]¶

Bases: object

A video file read lazily: video[i] is frame i as an <image>.

Frames are decoded on demand by ffmpeg (seeking for single frames, one stream for iteration), so long videos cost nothing until used. Combine footage with vector graphics in an animation update callback, for instance backdrop.pixels = video.at(seconds).pixels.

Parameters:

  • path (str or os.PathLike) – Any file ffmpeg can read (mp4, webm, mov, gif, …).

  • ffmpeg (str, optional) – The ffmpeg executable. Defaults to None (found on PATH or SVGWRITER_FFMPEG).

Variables:

  • height (width,) – Frame size in pixels.

  • fps (float) – Frames per second.

  • duration (float) – Length in seconds.

Raises:

  • FFmpegNotFoundError – If ffmpeg is not installed.

  • FFmpegError – If the file has no video stream ffmpeg can read.

See also

svgwriter.Document.render_animation

The other direction, drawings into video.

Examples

>>> from svgwriter.video import Video
>>> # clip = Video("clip.mp4"); first = clip[0]; len(clip), clip.fps

iter_frames(document: Document, fps: float = 30.0, duration: float | None = None, renderer: Renderer | str | None = None, *, update: Update | None = None) → Iterator[Frame][source]¶

Render one frame per 1/fps seconds without encoding them.

Frames are produced lazily, so the document can be changed by update between them.

Parameters:

  • document (Document) – The drawing.

  • fps (float, optional) – Frames per second. Defaults to 30.0.

  • duration (float, optional) – Seconds to render. Defaults to the end of the document’s SMIL animations.

  • renderer (callable, str or None, optional) – renderer(document, seconds), a registered name such as "skia" or "module:function". Defaults to None, which raises; there is no default renderer.

  • update (callable, optional) – update(document, seconds) called before each frame. Defaults to None.

Yields:

Frame – The checked frame for each sample time.

Raises:

ValueError – If no renderer is given, or no duration is given and the document has no plain-clock SMIL animation.

See also

render_animation

Encode the frames into a file.

Examples

>>> import svgwriter as svg
>>> from svgwriter.video import iter_frames
>>> doc = svg.Document(8, 6)
>>> [(f.index, f.width, f.height) for f in iter_frames(doc, fps=2, duration=1, renderer="skia")]
[(0, 8, 6), (1, 8, 6)]

render_animation(document: Document, path: AnyPath, fps: float = 30.0, duration: float | None = None, renderer: Renderer | str | None = None, *, update: Update | None = None, ffmpeg: str | None = None) → Path[source]¶

Render frames and encode them with ffmpeg.

ffmpeg is located first, so a missing executable fails before any frame is rendered. Frames are piped to a single ffmpeg process.

Parameters:

  • document (Document) – The drawing.

  • path (str or path-like) – Output file; the extension picks the encoder (.mp4, .gif, .webm, .mov, .apng, anything else ffmpeg knows).

  • fps (float, optional) – Frames per second. Defaults to 30.0.

  • duration (float, optional) – Seconds to render. Defaults to the end of the document’s SMIL animations.

  • renderer (callable, str, optional) – renderer(document, seconds) returning PNG bytes or an (height, width, 4) uint8 array; a registered name such as "skia"; or "module:function". Defaults to None, which raises; there is no default renderer.

  • update (callable, optional) – update(document, seconds) called before each frame, for procedural animation. Defaults to None.

  • ffmpeg (str, optional) – The ffmpeg executable. Defaults to ffmpeg found on PATH.

Returns:

pathlib.Path – The written file.

Raises:

  • FFmpegNotFoundError – Before rendering anything, when ffmpeg is missing.

  • FFmpegError – When ffmpeg fails.

  • ValueError – If no renderer or duration can be determined.

See also

iter_frames

The frames without encoding.

Examples

>>> import svgwriter as svg
>>> from svgwriter.video import FFmpegNotFoundError, render_animation
>>> doc = svg.Document(8, 6)
>>> try:
...     render_animation(doc, "out.gif", duration=1, renderer="skia", ffmpeg="no-such-ffmpeg")
... except FFmpegNotFoundError:
...     print("ffmpeg is required")
ffmpeg is required
