Animation export¶

Scenes, frame rendering and ffmpeg encoding. svg.Scene is exported at the top level as well.

svgwriter.motion.video.Scene([document, name])

An animation: a drawing built once, then changed over time.

svgwriter.motion.video.Scene.attach(element, ...)

Run behavior on element before every frame: behavior(element, seconds, *args, **kwargs).

svgwriter.motion.video.Scene.bake([fps, ...])

A copy of the document whose SMIL plays what the behaviors and update() do.

svgwriter.motion.video.load_scenes(source[, ...])

Collect scenes from a script, a module or an .svg file.

Turning documents into video and GIF files through ffmpeg.

svgwriter does not rasterize by itself. A renderer is any callable renderer(document, seconds) returning PNG bytes or an (height, width, 4) uint8 RGBA array; frames are piped to ffmpeg. The "skia" renderer is built in. A Scene subclass bundles a drawing, its update and its settings, so one file can hold several animations.

Example

>>> import svgwriter as svg
>>> doc = svg.Document(64, 64)
>>> dot = doc.circle(32, 32, 4, fill="tomato")
>>> def grow(document, t):
...     dot.r = 4 + 20 * t
>>> doc.render_animation("grow.gif", fps=12, duration=1, renderer="skia", update=grow)
class Scene(document: Document | None = None, *, name: str | None = None)[source]¶

Bases: SceneMotion

An animation: a drawing built once, then changed over time.

Subclass it, set the class attributes and override build() and, for procedural motion, update(); attach() adds reusable behaviors. SMIL animations in the drawing play as well. Saving as SVG or PowerPoint bakes the Python motion into SMIL (bake()). One file can hold several scenes; svgwriter animate renders each one.

Parameters:

  • document (Document, optional) – A finished drawing to animate as it is, instead of calling build(). Defaults to None.

  • name (str, optional) – The scene’s name, used for output files. Defaults to the class name.

Variables:

  • height (width,) – Size of the document handed to build(). Default 640 by 360.

  • size (str, PageSize or None) – A named size instead ("video-1080p", svg.size.instagram_story, … see size); it sets width and height. Default None.

  • fps (float) – Frames per second. Default 30.0.

  • duration (float or None) – Seconds to render. Default None, the end of the SMIL animations.

  • renderer (callable or str) – renderer(document, seconds), a registered name or "module:function". Default "skia".

See also

svgwriter.motion.video.load_scenes

Collect the scenes of a file or module.

svgwriter.motion.video.render_animation

The encoder underneath save().

Notes

build() receives an empty document of the class’s size rather than returning one, so width and height mean one thing and the method holds only drawing code. It runs when the scene is created, so the elements it stores are there before the first update(). Keep the elements that update() changes on self. update() receives absolute time, so frames can be rendered in any order and a scene can be saved more than once.

Examples

>>> import svgwriter as svg
>>> class Grow(svg.Scene):
...     width, height, fps, duration = 40, 40, 4, 1.0
...     def build(self, doc):
...         self.dot = doc.circle(20, 20, 4, fill="tomato")
...     def update(self, seconds):
...         self.dot.r = 4 + 12 * seconds
>>> scene = Grow()
>>> [frame.index for frame in scene.frames()]
[0, 1, 2, 3]
>>> scene.render(0.5)[:4]
b'\x89PNG'
>>> scene.save("grow.gif")
>>> class Story(svg.Scene):
...     size = "instagram-story"
>>> Story.width, Story.height
(1080.0, 1920.0)

class Video(path: AnyPath, *, ffmpeg: str | None = None)[source]¶

Bases: object

A video file read lazily: video[i] is frame i as an <image>.

Frames are decoded on demand by ffmpeg (seeking for single frames, one stream for iteration), so long videos cost nothing until used. Combine footage with vector graphics in an animation update callback, for instance backdrop.pixels = video.at(seconds).pixels.

Parameters:

  • path (str or os.PathLike) – Any file ffmpeg can read (mp4, webm, mov, gif, …).

  • ffmpeg (str, optional) – The ffmpeg executable. Defaults to None (found on PATH or SVGWRITER_FFMPEG).

Variables:

  • height (width,) – Frame size in pixels.

  • fps (float) – Frames per second.

  • duration (float) – Length in seconds.

Raises:

  • FFmpegNotFoundError – If ffmpeg is not installed.

  • FFmpegError – If the file has no video stream ffmpeg can read.

See also

svgwriter.Document.render_animation

The other direction, drawings into video.

Examples

>>> from svgwriter.motion.video import Video
>>> # clip = Video("clip.mp4"); first = clip[0]; len(clip), clip.fps

load_scenes(source: str | Path, names: Sequence[str] = ()) → list[Scene][source]¶

Collect scenes from a script, a module or an .svg file.

source is a path to a Python file, an importable module name, either one followed by :Name, or an .svg file. Without names, every Scene subclass the file or module defines is returned, in definition order; classes whose names start with _ are skipped, so a shared base class can be private. A name may also refer to a scene instance or a Document.

Parameters:

  • source (str or pathlib.Path) – "scenes.py", "scenes.py:Intro", "pkg.scenes:Intro" or "drawing.svg".

  • names (sequence of str, optional) – Scenes to pick, in this order. Defaults to all of them.

Returns:

list of Scene – New instances, ready to save.

Raises:

SceneError – If nothing matches, or a name is not a scene.

See also

render_animation(document: Document, path: AnyPath, fps: float = 30.0, duration: float | None = None, renderer: Renderer | str | None = None, *, update: Update | None = None, ffmpeg: str | None = None) → Path[source]¶

Render frames and encode them with ffmpeg.

ffmpeg is located first, so a missing executable fails before any frame is rendered. Frames are piped to a single ffmpeg process.

Parameters:

  • document (Document) – The drawing.

  • path (str or path-like) – Output file; the extension picks the encoder (.mp4, .gif, .webm, .mov, .apng, anything else ffmpeg knows). A .png path writes numbered frames beside it instead: intro.png becomes intro_0000.png, intro_0001.png and so on.

  • fps (float, optional) – Frames per second. Defaults to 30.0.

  • duration (float, optional) – Seconds to render. Defaults to the end of the document’s SMIL animations.

  • renderer (callable, str, optional) – renderer(document, seconds) returning PNG bytes or an (height, width, 4) uint8 array; a registered name such as "skia"; or "module:function". Defaults to None, which raises; there is no default renderer.

  • update (callable, optional) – update(document, seconds) called before each frame, for procedural animation. Defaults to None.

  • ffmpeg (str, optional) – The ffmpeg executable. Defaults to ffmpeg found on PATH.

Returns:

pathlib.Path – The written file, or the %04d pattern of the numbered PNG frames.

Raises:

  • FFmpegNotFoundError – Before rendering anything, when ffmpeg is missing.

  • FFmpegError – When ffmpeg fails.

  • ValueError – If no renderer or duration can be determined.

See also

iter_frames

The frames without encoding.

Examples

>>> import svgwriter as svg
>>> from svgwriter.errors import FFmpegNotFoundError
>>> from svgwriter.motion.video import render_animation
>>> doc = svg.Document(8, 6)
>>> try:
...     render_animation(doc, "out.gif", duration=1, renderer="skia", ffmpeg="no-such-ffmpeg")
... except FFmpegNotFoundError:
...     print("ffmpeg is required")

Behaviours¶

Built-in behaviors: Python motion a Scene runs before every frame.

Each one starts from the element’s home and moves it relative to that, about its anchor, so it never drifts. Attach one by name (element.animate.wiggle()) or typed (scene.attach(element, wiggle, angle=10)).

Example

>>> import svgwriter as svg
>>> from svgwriter.motion.video.behaviors import wiggle
>>> class Alarm(svg.Scene):
...     width, height, duration = 40, 40, 1.0
...     def build(self, doc):
...         self.bell = self.attach(doc.rect(10, 10, 20, 20), wiggle, angle=15)
>>> scene = Alarm()
>>> scene.update(0.0)
>>> scene.render(0.125)[:4]
b'\x89PNG'
