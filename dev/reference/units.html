Units¶

Lengths, angles and quantities, and the unit factories svg.mm, svg.inch, svg.deg, … A unit on its own is one of itself (height=svg.inch). Units SVG has no suffix for (metres, feet, miles, …) are written in the nearest SVG unit.

Lengths, angles and their units: svg.mm(5), 5 * svg.inch, svg.Length, svg.Angle, svg.Quantity.

Units SVG has no suffix for (metres, feet, miles, …) are written in the nearest SVG unit, so every value converts back to SVG.

class Angle(value: float, unit: str = 'deg')[source]¶

Bases: object

An angle with a unit; float(angle) is degrees, as every svgwriter rotation expects.

Any two angles add, subtract and compare whatever their units; plain numbers count as degrees, as in SVG. Positive angles turn from +x towards +y, which is clockwise on screen. Multiplying or dividing by lengths and angles gives a ~svgwriter.model.units.quantities.Quantity.

Parameters:

  • value (float) – The magnitude.

  • unit (str, optional) – "deg", "rad", "grad" or "turn", or a spelled-out name ("degrees", "radians", "gon", "turns", …). Defaults to “deg”.

Examples

>>> import svgwriter as svg
>>> float(svg.turn(0.25)), str(svg.rad(1) + 30)
(90.0, '1.5236rad')
>>> svg.rect(0, 0, 4, 2).rotate(svg.rad(math.pi / 2)).matrix.decompose()[2]
90.0
>>> str(Angle(2, "radians"))
'2rad'

class Length(value: float, unit: Unit = Unit.NONE)[source]¶

Bases: object

A number with an optional unit.

The unit may be spelled out ("millimetres", "inches"); metres and feet are accepted too and stored as millimetres and inches, since SVG has no such units. Multiplying or dividing by other lengths and angles gives a ~svgwriter.model.units.quantities.Quantity (an area, for instance) that turns back into a length when the dimensions cancel.

Parameters:

  • value (float) – The magnitude.

  • unit (Unit or str, optional) – The unit; Unit.NONE means user units. Defaults to Unit.NONE.

One of a unit, usable as a length or as a factory: mm(5), 5 * mm and height=inch.

A unit is a Length of 1 in that unit, so it goes anywhere a length does. Units SVG has no name for (metres, feet, miles…) are written in the nearest SVG unit.

Parameters:

class Quantity(value: float, length: int = 0, angle: int = 0, length_unit: Unit | None = None, angle_unit: str = 'rad')[source]¶

Bases: object

A value of dimension length^n · angle^m, the result of multiplying or dividing lengths and angles.

Arithmetic works like a maths problem: products add exponents, quotients subtract them, and sums need equal dimensions. Results that are plain lengths, angles or numbers come back as Length, Angle or float, in the unit of the first length or angle involved.

Parameters:

  • value (float) – Magnitude in user units^length · radians^angle.

  • length (int, optional) – Exponents of length and angle. Default to 0.

  • angle (int, optional) – Exponents of length and angle. Default to 0.

  • length_unit (Unit, optional) – Unit used to show lengths and to give back a Length. Defaults to user units.

  • angle_unit (str, optional) – Unit used to show angles and to give back an Angle. Defaults to “rad”.

See also

dimension_name

How a dimension reads.

Examples

>>> import svgwriter as svg
>>> area = svg.mm(3) * svg.mm(2)

('6mm²', 'length²')

The quantity behind a length, angle, number or quantity.

Parameters:

value (Length, Angle, Quantity or float) – The value; lengths must be absolute (not em, ex or %).

Returns:

Quantity – The value in base units with its exponents.

Raises:

  • TypeError – If the value is not a number, length, angle or quantity.

  • ValueError – If a length is relative.

Examples

>>> import svgwriter as svg
>>> Quantity.of(svg.inch(1)).value
96.0
property dimension: str¶

The dimension as text, such as "length²".

simplify() → Quantity | Length | Angle | float[source]¶

This value as a Length, Angle or float when its dimension allows.

Returns:

Quantity, Length, Angle or float – The simplest type for the dimension.

Examples

>>> Quantity(2.0, 0, 0).simplify()
2.0
dimension_name(length: int, angle: int) → str[source]¶

How a dimension reads in messages: "length²", "length·angle⁻¹", "number".

Parameters:

  • length (int) – The exponents of length and angle.

  • angle (int) – The exponents of length and angle.

Returns:

str – The dimension written with superscript exponents.

Examples

>>> from svgwriter.model.units.quantities import dimension_name
>>> dimension_name(2, 0), dimension_name(1, -1), dimension_name(0, 0)
('length²', 'length·angle⁻¹', 'number')
