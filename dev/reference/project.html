Project¶

Design projects: the manifest, building, previews and presets. See the Projects guide.

class Project(config: ProjectConfig)[source]¶

Bases: object

A design project: a folder with svgwriter.toml, the code that draws it and the files it builds.

The manifest names the entry ("main:build", a function that draws into a document of the project’s size and theme), the theme file and the output formats. [tool.svgwriter] in pyproject.toml works as well, with the same keys. Nothing is read implicitly: importing svgwriter or creating a document never looks for a manifest; only load() and the svgwriter build and svgwriter preview commands do.

Parameters:

config (ProjectConfig) – The settings, usually from load().

See also

svgwriter.tools.project.presets

Register a starter folder for new().

Notes

The entry may be a function taking a Document, a Scene class, or a list of either (one slide or page each), and may live in a notebook ("main.ipynb:build"). Modules the project imports, and the animations and sizes they register, are forgotten after each build, so a build always runs the current files.

Examples

>>> import svgwriter as svg, tempfile
>>> with tempfile.TemporaryDirectory() as folder:
...     project = svg.Project.new(f"{folder}/card", preset="blank")
...     print([path.name for path in project.build()])
['card.svg', 'card.png']

Read the project whose manifest is in path or the nearest folder above it.

svgwriter.toml comes first; otherwise a pyproject.toml with a [tool.svgwriter] table.

Parameters:

path (str or os.PathLike, optional) – Where to start looking. Defaults to the current folder.

Returns:

Raises:

>>> with tempfile.TemporaryDirectory() as folder:

Create a project folder from a preset and load it.

  • path (str or os.PathLike) – The new folder; it must not exist or be empty.

build(formats: Sequence[str] | None = None, *, values: Mapping[str, Any] | None = None) → list[Path][source]¶

Draw the project and write its outputs into the output folder.

Fonts in the font folder are registered first, the theme applies to every page and scene (also to scenes the entry module makes when it is imported), and the project’s code runs in the project folder, so relative paths such as assets/data/values.csv work.

Parameters:

  • formats (sequence of str, optional) – Formats to write. Defaults to None, the [outputs] formats of the manifest.

  • values (mapping, optional) – Values for the controls the entry declares (svgwriter.tools.widgets.controls()), by parameter name. Defaults to None, their starting values.

Returns:

list of pathlib.Path – The files written, in format order.

Raises:

ProjectError – If the entry, the theme or a format cannot be found.

Notes

With a notebook entry, a call from inside that notebook uses the notebook’s own entry object; any other call runs the notebook in a new kernel (the notebook extra) and builds there, so both write the same files.

Examples

>>> import svgwriter as svg, tempfile
>>> with tempfile.TemporaryDirectory() as folder:
...     project = svg.Project.new(f"{folder}/sheet", preset="poster")
...     print([path.name for path in project.build(["svg"])])
['sheet.svg']

serve(port: int | None = None, *, open_browser: bool | None = None) → None[source]¶

Serve a live preview at http://127.0.0.1:<port> until interrupted (Ctrl+C).

The page shows every page and scene as SVG, drawn in memory. Controls the entry declares (svgwriter.tools.widgets.controls()) appear in a panel beside or below the drawing, and the drawing follows them as they move. Saving a file imports the project again and redraws; once the project has been quiet for a moment the output files are written too, as the page’s Export button does. A failed drawing shows its traceback under the last drawing that worked. The manifest’s [preview] table (PreviewConfig) sets the layout, backdrop, port and more.

Parameters:

  • port (int, optional) – The local port. Defaults to None, [preview] port (8000).

  • open_browser (bool, optional) – Open the page in the default browser. Defaults to None, [preview] open (True).

See also

preview

The output files inline in a notebook.

Examples

>>> import svgwriter as svg
>>> svg.Project.load().serve()

Bases: object

How svgwriter preview shows a project, read from the manifest’s [preview] table.

Parameters:

  • pages (tuple of str or None) – The pages and scenes to show, by output name, in this order. None shows all of them.

  • background (str) – Behind the drawing: "checker", "light", "dark" or a colour.

  • layout (str) – Where the controls sit: "auto" (right of the drawing on wide windows, below it otherwise), "right" or "bottom".

  • fit (str) – "contain" scales the drawing to its area; "actual" shows it at its own size.

  • port (int) – The local port.

  • open (bool) – Open the page in a browser on start.

  • debounce_ms (int) – Milliseconds the page waits after a control moves before asking for a new drawing.

  • build_on_save (bool) – Write the outputs after a file is saved and the project has been quiet for a moment.

  • formats_on_build (tuple of str or None) – The formats that saving and the page’s Export button write. None writes [outputs] formats.

>>> PreviewConfig().layout, PreviewConfig().port

class Preset(name: str, description: str, directory: Path, extends: str | None = None)[source]¶

Bases: object

A starter project: a folder of files, optionally laid over another preset’s.

In the folder, a -tpl suffix is dropped from file names (main.py-tpl becomes main.py, so the templates are not importable modules) and a dot- prefix becomes a dot (dot-gitignore). Text files have {{ project_name }} and {{ preset }} replaced.

Parameters:

  • name (str) – The name given to svgwriter new --preset.

  • description (str) – One line for svgwriter presets.

  • directory (pathlib.Path) – The folder copied into the new project.

  • extends (str or None, optional) – A preset whose files are copied first. Defaults to None.

Examples

>>> import svgwriter as svg
>>> svg.project.presets.get("poster").extends
'blank'

presets¶

what svgwriter new NAME --preset <name> and Project.new() start from.

Register a Preset with register() (its folder must exist and extends name a registered preset); svgwriter presets lists them. Packages add presets through the svgwriter.project_preset entry-point group.
