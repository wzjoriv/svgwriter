Preset libraries¶

Ready-made patterns, gradients, filters, markers and text effects; see the Presets guide for pictures of each. @svg.preset.pattern, filter, gradient, marker and text_effect (documented under Composite shapes and effects) add your own to these catalogues.

Ready-made patterns, used as paints: fill=svg.patterns.stripes(angle=45, gap=6).

Every pattern returns a Pattern in user units that goes into the document’s <defs> when an element refers to it. Shapes take the theme role "pattern" (the palette’s primary color) unless a color= or another role= is given; background= fills behind them. Patterns registered with svgwriter.preset.pattern() answer here too, and a built-in replaced with replace=True answers with the replacement.

Example

>>> import svgwriter as svg
>>> doc = svg.Document(60, 40)
>>> box = doc.rect(0, 0, 60, 40, fill=svg.patterns.hatch(gap=4, color="slategray"))
>>> doc.root.defs()[0].tag
'pattern'

Ready-made gradients, used as paints: fill=svg.gradients.sunset().

Blends between distant colors are sampled in OKLCH, so they stay vivid where a plain sRGB blend turns grey. Gradients are in bounding-box units, so one paint stretches to any shape; mesh is a pattern of layered radial blends. Colors left to the theme come from Theme.current when the gradient is built. Gradients registered with svgwriter.preset.gradient() answer here too.

Example

>>> import svgwriter as svg
>>> doc = svg.Document(80, 40)
>>> sky = doc.rect(0, 0, 80, 40, fill=svg.gradients.sunset())
>>> doc.root.defs()[0].tag
'linearGradient'

Ready-made filters: element.filter = svg.filters.glow(4).

Every function returns a Filter that goes into the document’s <defs> when an element refers to it, with a region enlarged so blurs and shadows are not clipped, computed in sRGB. Single colors (shadows, outlines) default to theme roles ("filter.shadow", "filter.ink"), so they follow the document theme. Filters registered with svgwriter.preset.filter() answer here too.

Example

>>> import svgwriter as svg
>>> doc = svg.Document(80, 40)
>>> card = doc.rect(10, 10, 50, 20, fill="white", filter=svg.filters.drop_shadow(2, 3, 2))
>>> doc.root.defs()[0].tag

Ready-made markers for line ends and vertices: marker_end=svg.markers.arrow().

Markers are sized in stroke widths, so heads grow with the line, and turn with it (orient="auto"). They take the line-end theme role "arrow.head" (the palette’s foreground) unless a color= is given, and go into the document’s <defs> when a line refers to them. Markers registered with svgwriter.preset.marker() answer here too.

Example

>>> import svgwriter as svg
>>> doc = svg.Document(80, 20)
>>> line = doc.line(5, 10, 70, 10, stroke="black", stroke_width=2, marker_end=svg.markers.arrow())
>>> doc.root.defs()[0].tag
'marker'
arrow(size: float = 5.0, *, color: Color | str | None = None, role: str | None = 'arrow.head', **kwargs: Any) → Marker[source]¶

A filled triangular arrowhead whose tip sits on the line’s end.

Every marker is sized in stroke widths, so a thicker line gets a proportionally larger head, and turns with the line (orient="auto").

Parameters:

  • size (float, optional) – Width and height in stroke widths. Defaults to 5.

  • color (Color or str, optional) – Fill. Defaults to None, which takes the theme role.

  • role (str or None, optional) – Theme role when no color is given. Defaults to "arrow.head" (the palette’s foreground); None draws black.

  • **kwargs – Forwarded to Marker.

Returns:

Marker – The marker; marker_end=svg.markers.arrow() puts it into <defs>.

Examples

>>> import svgwriter as svg
>>> head = svg.markers.arrow(color="red")
>>> head.get("orient"), head.get("refX"), head[0].get("fill")
('auto', 10.0, 'red')

Text effects that stay text: svg.text_effects.fire(text[4:9]) or text[4:9].effect("fire").

Each effect sets paint, a filter and, unless animate=False, a small SMIL loop, so the effect plays in browsers, GIFs and videos alike. The glyphs are never turned into outlines: the text stays selectable and searchable. On a range, the characters move onto a copy of the text placed just above it (see CharacterRange.isolate), so filters reach exactly those characters; the text must already be in a document or group. Effects registered with svgwriter.preset.text_effect() answer here too.

Example

>>> import svgwriter as svg
>>> doc = svg.Document(300, 50)
>>> line = doc.text("Smoke and Snow", x=10, y=36, font_size=28)
>>> _ = svg.text_effects.smoke(line[0:5])
>>> _ = line[10:14].effect("snow")
>>> len(doc.root.find_all(svg.Text))
3
fire(text: Text, *, animate: bool = True, seed: int = 0) → None[source]¶

Burning letters: a white-hot to ember gradient, licked upwards by flickering noise, with an orange glow.

Parameters:

  • text (Text) – The text, or (through the registered effect) a range such as text[4:9].

  • animate (bool, optional) – Let the flames flicker (an SMIL loop, so it plays in browsers, GIFs and videos). Defaults to True.

  • seed (int, optional) – Noise seed; other seeds give other flames. Defaults to 0.

Examples

>>> import svgwriter as svg
>>> doc = svg.Document(240, 60)
>>> line = doc.text("carried sparks", x=10, y=40, font_size=28)
>>> layer = svg.text_effects.fire(line[8:14])
>>> layer.get("filter").element[0].children[0].get("attributeName")
'baseFrequency'
